# Claim contract

- **Input:** the actual branch partition used by `imgfib`.
- **Output:** one exact descriptor per branch occurrence charged to
  Conjecture F, with a bijection to the counted codeword or section-point
  occurrences.
- **Must preserve:** received word, canonical punctured domain, locator
  degree, projective dimension, root threshold, first owner, and
  multiplicity.
- **Available proved cells:** coordinate/MDS fibers and the punctured
  root-free rational-Q projective cell.
- **Nonclaim:** the full Pade section is linear; the root-free boundary cell
  exhausts all mixed-petal records; an evidence edge is a branch compiler.
