# XR forced-common-root syzygy count

- **status:** TARGET
- **parent:** `xr_band_maximal_window_divisor_count`

In the setup of SL-2-RES, assume `rank J_d<2d`. Let `G_d` be the set
of evaluation points at which both reversed coefficient polynomials of
every left syzygy vanish. In the only deficient stratum not paid by
the rational-direction theorem, assume

```text
|G_d| >= 2(h-d).
```

Then the maximal, selected, post-strip locator set satisfies

```text
25 |R_d(u,v)| <= 17 n^2.
```

This is a common-factor structural census. It is not the assertion
that one conveniently chosen syzygy has many roots: the roots are
forced on the entire left kernel.

root count and more than `17n^2/25` maximal selected post-strip
locators.
