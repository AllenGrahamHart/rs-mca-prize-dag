# Attack

1. Use LS6 exactly; do not replace its guarded split-divisor set by every
   vector in the ambient linear slice.
2. Work on one fixed source, touched triple, defect `a`, and its determined
   cross-ratio `lambda`. First-layout atom collapse already pays all outer
   composition with fewer than `4n` cells and four anchors.
3. Test max-to-mean, quotient/field-drop, exchange, and collective
   split-divisor routes against the explicit Johnson-negative tail.
4. A per-cell polynomial whose exponent grows with `ell` is not a payment.
5. Falsification should search for superpolynomial guarded LS6 fibers, not
   large unguarded linear slices or artificial sums over `lambda`.
