=== forced lower bound on w* ===
  an unsupported generic-rank slope has coset weight >= R+1-rho = 4m+2,
  and coset weight <= w*, so w* >= 4m+2 whenever some slope is
  unsupported (always, since T <= rho+2 < q).
  and w* <= |S_i u S_j| <= 2rho = 8m-2 whenever T >= 2.
  => w* lives in [4m+2, 8m-2], a window of width 4m-3.
