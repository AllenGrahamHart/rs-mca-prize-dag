## D1 — THE FORCED-FIXED LEMMA IS FALSE

### D1.1 Where the inference breaks (one word: Forney)

Round 32's chain (`rh_farca_upper/REPORT.md:178`, banked verbatim at
`critical/nodes/rate_half_band_crossing_location/statement.md:1003-1006`)
is: the kernel splits as `m_P = r+1-p` shifts of `P_Z` and
`m_Q = r+p-R` shifts of `Q'_Z`; a moving generator makes all of its
shifts have Kronecker index `>= 1`; the Kronecker identity
`sum eps + sum eta + delta = rho` caps the total; since
`m_P + m_Q = r+1-rho > rho`, one generator must be fixed.

The failure is at step two. The Kronecker identity constrains the
**minimal** indices — the degrees of a *minimal* polynomial basis of the
kernel module. The shift set `{x^j P_Z} ∪ {x^i Q'_Z}` spans the rational
kernel but is **not** in general a minimal basis, and Forney's inequality
runs the *other* way: **every** polynomial basis has degree sum `>=` the
sum of the minimal indices. So `m_P e_P + m_Q e_Q >= sum eps`, which
places **no upper bound** on `m_P e_P + m_Q e_Q` and therefore forces
nothing. The two-generator shift basis is minimal only if the combined
leading-coefficient matrix has full rank, i.e. only if
`deg gcd(lead_Z P_Z, lead_Z Q'_Z) <= rho`; the node's own single-
generator proof is careful to establish exactly this
(`background/nodes/rate_half_ca_hankel_minimal_index_budget/proof.md:59-72`:
"*their leading coefficient vectors are independent shifts of the nonzero
leading form*"), and round 32 imported the conclusion without the
hypothesis.

At the razor the gap is quantified: the shift basis has degree sum
`>= m_P + m_Q = 1,065,151,889,409 = 2^39.954196`, while the minimal
indices sum to `<= rho = 2^34`. **Forney gap factor `2^5.9542`**
(`e3_razor_results.txt`).

### D1.2 The correct invariants

For the pencil `M(Z) = M_r(y_0) + Z M_r(y_1)`, with
`K_0 = ker M_r(y_0) ∩ ker M_r(y_1)`:

```

dim K_0 = r+1 - h_r ,      rho <= h_r <= 2rho ,

```

`K_0 = Ann(V)_r` for the 2-dimensional space `V = <Phi_0, Phi_1>` of
binary forms of degree `R-1`, i.e. the degree-`r` piece of the annihilator
of the **pencil**, not of any one slope. Define

```

p*    = min{ i : Ann(V)_i != 0 }                              (minimal COMMON apolar degree)

Then **`P_gamma` is fixed iff `p* <= p_gen`** (hence `= p_gen`, and
`P_gamma = P*`). Generic values, from `h_i = min(i+1, R-i)` and

```

**`p* > p_gen` for all `R >= 4`, so GENERICALLY NEITHER GENERATOR IS
FIXED.** At the razor `p* = 733,007,751,851 = 2^39.415037` against
`p_gen = 549,755,813,888 = 2^39` (`e3_razor_results.txt`).

### D1.3 The correct replacement lemma, and by how much it misses

> **LEMMA (sufficient condition for a fixed generator).** Let `P*` be a
> nonzero common apolar form of minimal degree `p*`. If
> ```
> p* + p_gen <= R          (equivalently p* < R+1-p_gen = deg Q'_gamma)
> ```
> then for generic `gamma`, `P* ∈ Ann(Phi_gamma)_{p*} = P_gamma·F[x]_{p*-p_gen}`
> (the `Q'_gamma` summand is empty by degree), so `P_gamma | P*`. A nonzero
> `P*` has finitely many degree-`p_gen` divisors while `gamma` ranges over
> infinitely many values, so `P_gamma` is constant: **`P` is fixed, and
> `p* = p_gen`.** ∎

This is the honest form of what round 32 wanted, and it is a hypothesis
on `(p*, p_gen)`, **not** on `(r, R, rho)` — the multiplicity arithmetic
never enters. At the razor the hypothesis **fails**:

```

and asymptotically `(2R/3 + R/2)/R = 7/6`, so the mechanism misses by a

### FG3 — NORMAL FORM: the reduced pencil is a SCALED VANDERMONDE

Let `P` be squarefree with roots `Z = {alpha_1,...,alpha_p}` over `F̄`.
Then `Phi_gamma` lies in the inverse system of `(P)`, i.e.

```
y_m(gamma) = sum_i c_i(gamma) alpha_i^m ,     c_i(gamma) = c_i^0 + gamma c_i^1
```

with the `c_i` **linear in gamma**. Since `P·F[x]_{<=r-p} ⊆ ker M(Z)`, the
pencil descends to `Lambda = F[x]/(P)` (dimension `p`), and in CRT
coordinates `u_i = sigma(alpha_i)`:

```
M̄(gamma) = W · diag(c_1(gamma),...,c_p(gamma)) ,
W = the rho x p Vandermonde on Z   (rows alpha_i^0,...,alpha_i^{rho-1}).
```

The whole wide-regime pencil collapses to a `rho x p` scaled Vandermonde
with `rho < p <= 2rho`. `ker W = V = {(h(alpha_i)/P'(alpha_i))_i :
deg h <= m_Q-1}` is **fixed**, independent of gamma.

### FG4 — THE KEY EQUATION (the wide-regime replacement for (MI1)/(MI2))

Let `C_gamma` be the interpolant of degree `< p` with
`C_gamma(alpha_i) = c_i(gamma) P'(alpha_i)`; it is linear in gamma. Then

> **`gamma` is CA-bad ⟺ there is `sigma ∈ D_r(D)` with**
> ```
> C_gamma · sigma  ≡  h   (mod P) ,     deg h <= m_Q - 1 = p - rho - 1 ,  h != 0 ,
> ```
> **and `h = 0` is exactly column-closeness.**

This is a Padé/key-equation shape: `rho` linear conditions, matching
`rank M̄ = rho`. Equivalently `C_gamma ≡ h·sigma^{-1} (mod P)`, so the
bad slopes are the intersection of the **line** `{C_0 + gamma C_1} ⊂ Lambda`
with the set of residues `h·sigma^{-1}`.
