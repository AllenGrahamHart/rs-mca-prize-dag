# Proof

## 1. (CS) Common support is forced

Let the pencil be column-far with two bad slopes `gamma_1 != gamma_2`,
witnessed by locators `S_1, S_2` of size `r`. Badness at `gamma_i` means the
syndrome `y_0 + gamma_i y_1` is realised by an error `u_i` supported on
`S_i`; solving the `R x r` linear system for `u_i` is exact, and the solution
is unique because the `R x r` evaluation matrix on `r <= R` distinct points
has full column rank.

Linearity of the syndrome map in the error gives

```text
syn(u_1) = y_0 + gamma_1 y_1,      syn(u_2) = y_0 + gamma_2 y_1,
```

a `2 x 2` invertible system for `(y_0, y_1)` since `gamma_1 != gamma_2`.
Inverting,

```text
e_0 = (gamma_2 u_1 - gamma_1 u_2)/(gamma_2 - gamma_1),
e_1 = (u_1 - u_2)/(gamma_1 - gamma_2)
```

satisfy `syn(e_0) = y_0`, `syn(e_1) = y_1`, and both are supported inside
`S_1 u S_2`. So the pencil is generated by two errors on a COMMON support:
this is a theorem about column-far pencils, not a modelling choice. The
verifier performs the whole chain numerically and checks both syndromes.

## 2. (DICT) The dictionary

On the common support write `chi = e_1/e_0`. The stacked matrix
`[M_r(y_0); M_r(y_1)]` acts on coefficient vectors of polynomials of degree
`<= r` by `sigma |-> (sum_x e_0(x) v_x x^i sigma(x))_i` and its
`e_1`-analogue. A polynomial `sigma` lies in `K_0` exactly when it
annihilates both weighted point functionals for all `rho` shifts, i.e. when
`sigma` vanishes on the support after the two-row reduction; the reduction
identifies the obstruction with the numerator/denominator degrees of `chi`.
The resulting rank is `rho + deg chi` and the kernel dimension is the
complementary `r + 1 - rho - d`. The measurement is exact and reproduces on
`32/32` rows here and `210/210` in the source, and crucially it is
INDEPENDENT of the support size `s`, which is what retires `h_r` as a
coordinate: `h_r` is `rho` plus a degree.

## 3. (LB1) uniqueness and the forced `T_1`

If `d = 1` then `chi` is a nonconstant affine map, hence injective on the
support. The support then has size exactly `r+1` (any larger support would
force `dim K_0 = r+1-rho-1 < 0` in the counting, and any smaller is the
control case `s = r`), so `|W| = r+1` and `f = |W| - r = 1`. Every value
`chi(t)` is attained once, and each value yields a structural slope
`gamma = -1/chi(t)` whose locator is `T \ {t}`, of size exactly `r`. Distinct
`t` give distinct `gamma`, so `T_1 = r+1` and the fibre floor
`ceil((r+1)/d) = r+1` meets the cap. The verifier exhibits and CHECKS the
annihilating locator of each of the `r+1` slopes rather than counting them.

## 4. (PSTAR) is POSED, and the failure is named

`p*` is defined as the least `i` for which there is a nonzero `P` of degree
`<= i` with `P x^j in K_0` for all `0 <= j <= r-i`. The proposed law
`p* = max(rho+d, floor((R+1+d)/2))` is a prediction, not a derivation. It
fails on the symmetric-T quadratic at the H2 shape at every field tested
(measured `6`, predicted `7`), so `p*` is not a function of `(R, rho, d)`.
Since `p* = 6` also holds at both `h_r = 3` and `h_r = 4` on H1, `p*` cannot
separate those strata either. Both facts are reproduced by the verifier as
POSITIVE assertions: the law is asserted to hold on the other `30` rows and
to FAIL on exactly the two named ones, so a future change in either direction
breaks the replay.

## 5. What is NOT proved

The `h_r = 2rho` branch (non-polynomial ratio) is carried from the source
bank and not re-derived here. Nothing here reaches razor scale: the verifier
runs at `q <= 349`, `rho = 2`, and the source bank at `q <= 999983`,
`rho <= 4`. Characteristic 2 is unmeasured everywhere.
