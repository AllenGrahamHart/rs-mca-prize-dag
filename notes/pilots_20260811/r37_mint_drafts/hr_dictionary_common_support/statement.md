## Model (anchor-2 conventions)

`D subset F_q`, `|D| = n`, `v_x = 1/prod_{y in D, y != x}(x-y)`,

```text
y_m = sum_x e(x) v_x x^m,      M_r(y) = (y_{i+j})_{0<=i<rho, 0<=j<=r},
rho = R - r,                   R = n - k.
```

Both syndromes come from errors on a common set `T`, with `e_0 = 1` on `T`
and `e_1 = L` on `T`, `d = deg L`. Put `h_r = rank[M_r(y_0); M_r(y_1)]` and
`K_0 = ker` of that stacked matrix.

## (DICT) The dictionary — h_r is not a coordinate, it is a degree

```text
h_r = rho + deg(e_1/e_0)        and        dim K_0 = r + 1 - rho - d,
```

on the common support, **independent of the support size `s`**; `h_r = 2rho`
when the ratio is not polynomial.

Verified here on `32/32` rows (`2` shapes `x` `2` fields `x` `8` families);
`210/210` across `5` razor-faithful shapes `x` `5` fields in the source bank.

## (CS) Common support is a THEOREM, not a family choice

> Any column-far pencil with two bad slopes is generated by two errors
> supported on `S_1 u S_2`.

Constructive: from two bad slopes `gamma_1 != gamma_2` with locators
`S_1, S_2`, solve for the weight-`<= r` errors `u_1, u_2` and set

```text
e_0 = (gamma_2 u_1 - gamma_1 u_2)/(gamma_2 - gamma_1),
e_1 = (u_1 - u_2)/(gamma_1 - gamma_2).
```

Then `syn(e_0) = y_0` and `syn(e_1) = y_1`, and `supp(e_0) u supp(e_1)` is
contained in `S_1 u S_2`. Verified exactly on `24` rows here (`12/12`, two
fields, in the source bank).

## (PSTAR) The p*(d) law — POSED, with NAMED failures

```text
p*(d) = max( rho + d,  floor((R+1+d)/2) ).                       (POSED)
```

Holds `205/210` in the source bank with **5 NAMED failures**, all the same
configuration: the **H2 symmetric-T quadratic** (`n=22, k=11, rho=2, r=9`,
`s = r+1 = 10`, `L = x^2`, symmetric support), at `5/5` fields, where the
measured value is `6` against the predicted `7`. This verifier reproduces the
failure at both fields it tests, and reproduces the law everywhere else
(`30/32`).

**`p*` is therefore NOT a function of `(R, rho, d)` and must not label
strata.** Two further consequences of record:

- **The `p*` converse is REFUTED:** `p* = 6` at both `h_r = 3` and
  `h_r = 4` (verified here at H1). `p*` is a strictly coarser invariant than
  `h_r`.
- **R-PSTAR-INTERMEDIATE is retired as a stratum**; only its top edge
  `floor(R/2)` survives, as LB1's sharp coordinate
  (`p*(LB1) = floor(R/2)+1 = 2^39+1`, exactly one integer above the
  intermediate band's top).

## The band above LB1 (the brief's antecedent, falsified)

The `h_r = rho+2` band is **not** moment-bound: it carries a structural floor
`ceil((r+1)/d)` that REACHES `r+1` (injective quadratic ratio, 5 shapes x 5

`rho=3`). FG's floorlessness is a property of witness B's particular `K_0`,
**not** of `h_r`. "LB1-limited" survives only as a VALUE (`r+1`), conditional
