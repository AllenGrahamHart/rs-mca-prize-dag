# Audit

1. The construction uses a nonsquare in `mu_(N/d)`, so the inversion has no
   fixed points and the count is exact rather than a lower bound.
2. The equality-of-slopes calculation proves injectivity on involution
   orbits.
3. The power map has exactly `d` domain preimages because `d|N` and the
   characteristic is prime to `N`.
4. Different quotient orbits have disjoint full preimages, so the resulting
   locators are pairwise coprime.
5. The independent checker reconstructs the `d=4`, `N=32` partition over
   `GF(97)` without using the primary verifier's orbit construction.
6. No critical status changes: this is a route fence, not a payment.
