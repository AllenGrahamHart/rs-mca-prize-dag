# Result

Every squarefree double-root survivor, shared or separated, satisfies

```text
j<=1,
G(t,x_*)=(g_*S_B^2/J)T_j,
T_j!=0,       deg T_j<=1,       gcd(T_j,S_B)=1.
```

The augmented coefficient-MDS condition is exactly the nonzero remainder
test `H|R_lambda`. The only local double-root profile not covered is
nonreduced `S_B`.
