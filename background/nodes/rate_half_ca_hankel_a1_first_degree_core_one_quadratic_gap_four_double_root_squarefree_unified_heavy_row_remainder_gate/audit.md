# Audit

1. Global `D_1` divisibility is assembled root by root: separated roots use
   type `[2]`, shared roots use the proved vanishing jet and type `[3]`, and
   supported-only roots use the minimal-locator kernel.
2. A correction center is not discarded in the shared case. The source
   partition shows it must already be the unique allowed padded-heavy center.
3. Therefore `j<=1` still holds without `gcd(g_*,S_B)=1`.
4. At a shared root, simplicity in `X` forces one normalized branch, so the
   supported and correction divisor coefficients add.
5. The fixed-row substitution error has one higher order than the Forney
   contact, preserving the exact valuation.
6. Exact correction orders make `T_j` nonzero and coprime to `S_B`; this is
   stronger than bare divisibility but still not a remainder exclusion.
7. The barycentric proof is coefficient interpolation and does not use
   support/correction coprimality.
