# Audit

- The classification uses both `p mod 4` order laws; neither valuation is
  substituted into the other branch.
- Generation means `ord_n(p)=e`, not merely `ord_n(p)|e`.
- The two minus types are distinct and both have explicit witnesses.
- Four witnesses use complete-factor Pocklington certificates; M61 uses
  Lucas--Lehmer. No probabilistic primality test is part of the proof.
- The field cap is checked on `q=p^e`, not on `p` alone.
