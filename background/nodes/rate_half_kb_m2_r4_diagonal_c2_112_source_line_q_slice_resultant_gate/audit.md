# Audit

1. `(KBQS-1)` is necessary, not sufficient: it sees only the two `J_1`
   rows and does not enforce the four `J_0` rows or the second quotient.
2. The forced root has multiplicity two in each `G(r,W)` because both `U`
   and `V` vanish there. The repaired ramified case is included.
3. The mixed fibers are unramified; otherwise their transported complete
   fibers would contradict squarefreeness of the colored divisor.
4. Nonzero `G(r,W)` uses reduced irreducibility of the actual source
   component. The conclusion is not asserted for an arbitrary degenerate
   coefficient tuple.
5. The split `F_1009` probe is evidence only and cannot delete the generic
   aligned branch.
