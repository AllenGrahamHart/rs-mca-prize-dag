# Result

The residual rank problem has a pivot-free scalar formulation. On the clean
frontier, the `h_m` coefficient block fails exactly when

```text
h_m(x)=Q(x)/P(x)
```

on all of `W`, with numerator and denominator degrees below
`r=|W|-(4m+1)`. If the unique deficient point lies in `W`, the same agreement
is required on the punctured support.

This isolates a possible scalar theorem target. The bounded random `m=2`
campaign found resistance in every sampled bad pattern, including the
punctured branch. A later adversarial inverse-pair construction has an exact
rational trace while satisfying the incidence/minimum-pair/bad-overlap
ledger. It fails the official coefficientwise locator-extension gate. Thus
the random zero-exception profile is not a universal incidence theorem; the
live proof must use locator extension or stronger Hankel structure.
