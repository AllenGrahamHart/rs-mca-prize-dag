# Audit - M31 top-pair source-head saturation router

1. `C_ij` counts common planted residual agreements, while
   `K_ij/L_S` counts common external residual agreements.
2. Top intersection equality is what turns determinant divisibility into
   equality; the selected-basis overlap theorem alone would not do this.
3. `gamma_i` is the coefficient of `X^(d-1)` in `f_i`, with value zero when
   `f_i` has lower degree. Monicity transfers it to the top allowed
   coefficient of `b_i`.
4. The scalar in `(HS1)` is a difference of head values, not an arbitrary
   decoration.
5. The `458812` cap counts actual supports in one head fiber and uses
   intersection `t-1`, not `t`.
6. The line cap for a fixed `(core,head)` pair is `15`; the anchor is not on
   that translated line, so no subtraction is made.
7. All large floors are lower bounds on spread. None is an upper payment.
