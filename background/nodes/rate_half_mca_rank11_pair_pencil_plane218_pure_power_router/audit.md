# Audit

1. `F<=re` counts full coordinates, not full affine lines. Each full
   coordinate has one direction and is one of at most `e` roots there.
2. The root count uses `e|N` and odd characteristic, so `X^e-y` is
   squarefree on `mu_N`.
3. The degree-2048 line conclusion uses both `r=218` and the independent
   218-line ceiling from the parent bank.
4. The degree-4096 missing-slot cap uses the worst permitted `r=218` and
   the smallest permitted `K'=4097`; it does not assert that all 218
   directions are represented.
5. Projective equivalence to a pure power is an explicit subclass
   hypothesis. No general rational-map classification is smuggled in.
