# Audit

1. The global calculation consumes the complete degree-16 resultant.
2. Every pseudo-reduction records its step count and only introduces powers
   of the printed plane-leading coefficient.
3. Proportionality is a zero quotient-ring cross identity.
4. The degree-2432 norm is factored exactly, and every base-field root is
   assigned either to the main atlas or the scale ledger.
5. The sole proper scale fiber is reconstructed in the original common
   ideal; no invalid compact denominator is reused there.
6. Both deployed exceptional points consume the unnormalized common kernel
   and the complete raw signed-pair resultant.
7. Every deployed main or exceptional root has an explicit original guard;
   nonlinear factors are irreducible over the deployed field.
8. Mutation tests reject changes to custody, identities, root ledgers,
   proper-fiber points, guard owners, and DAG status.
