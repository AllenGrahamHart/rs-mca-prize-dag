# Claim contract

- **Claim:** every quadratic minimum pair has a linear-size common parameter
  gcd; in the zero/zero case the two oriented gcd root sets exchange the
  endpoints and the six residual root sets are disjoint.
- **Inputs:** the oriented rank-two normal forms, exact absence of endpoint
  padding at deficit zero, full-locator minimum-distance line ownership, and
  projective linearity of the residual word pencil.
- **Outputs:** source-exclusion bound `(OGC1)`, oriented coupling `(OGC2)`,
  six-set root budget `(OGC3)`, and universal piecewise bound `(OGC5)`.
- **Falsifier:** a source slope in an oriented row-root union, a nonendpoint
  common-gcd root absent from the reverse gcd, or a shared forward/reverse
  residual root whose center remains off the endpoint pencil.
- **Nonclaims:** no contradiction with the center-line cap, no heavy-row
  factor identification, and no minimum-pair exclusion.
