# Audit

1. Base-freeness excludes zero evaluation columns, so projective
   proportionality gives a common codimension-one kernel rather than an
   undefined projective class.
2. The locator uses distinct deployed field points and is squarefree.
3. Division is applied to polynomial spaces, not merely their evaluation
   vectors; the degree-`<K` factor presentation supplies the degree bound.
4. The upper clone-size bound is `K-5`, not merely `K-1`, because the
   shortened product space has dimension at least `2+4-1=5`.
5. The adapter deletes one common coordinate set from one first-owned
   bucket. It does not add charges over overlapping clones.
6. First-match mass is transported, not recomputed from a local list cap.
7. The output is a typed residual family and remains unpaid.
