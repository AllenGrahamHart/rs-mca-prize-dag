# Audit

1. Rank-deficient component incidences are retained and paid explicitly;
   the full component density is not assigned wholesale to the affine lane.
2. At `K'=12`, only corank one has a nonzero canonical-basis extension
   factor because `C(2,d+1)=0` for `d>=2`.
3. The rank-nine chart cap takes the maximum over all honest core sizes
   `j=9,10,11` before global summation.
4. The circuit-shadow criterion uses the one-dimensional intersection
   `Lambda intersect E_T`; this prevents a second quotient label from
   appearing in a nine-shadow.
5. High-circuit marks stay in `(record,T,B)` units.
6. Low circuits are bounded per selected record support by the separate
   quotient-line theorem; no secant-line classification is assumed.
7. Kernel and high-circuit capacities are independent of `R_actual`, while
   the demand-minus-low coefficient is positive.  Checking `N_min` is
   therefore sufficient.
8. The result closes only `K'=12`; it does not extrapolate the line argument
   to the projective quotient plane at `K'=13`.
