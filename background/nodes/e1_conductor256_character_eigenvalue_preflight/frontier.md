# Frontier

precision or enumerating the `2^143` coarse body.

The next positive theorem must start from the exact equation

```text
pi^mu beta = u pi^mu alpha
```

for two profile-`(3,6,S=18)` sparse vectors and use both directions:

```text
beta=u alpha,       alpha=u^(-1) beta.
```

Promising admissible outputs are:

1. a support-propagation theorem showing that bounded `u` and `u^(-1)` can
   map one six-singleton/three-doubleton vector to another only in finitely
   many classified exponent patterns;
2. an exact coefficient recurrence that rejects a unit exponent prefix
   before the Fourier body is generated; or
3. a sparse-first branch-and-bound whose complete state count, peak RAM,
   wall time, and cost are conservatively below the repository limits.

Any surviving maximum-weight count must still be summed across four
cofactors and combined with the lower-profile weighted ledger.
