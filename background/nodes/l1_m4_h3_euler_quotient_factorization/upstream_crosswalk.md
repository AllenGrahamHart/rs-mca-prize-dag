# Upstream crosswalk - m4/h3 Euler quotient factorization

For the upstream base-field-normalized split-pencil census, `(EQF3)` is an
exact derivative-elimination ledger for the four surviving low-defect cases.
It replaces an unconstrained degree-`p` derivative with an Euler derivative
whose exact degree is within three of its maximum and pins the eliminant away
from zero.

This is suitable for an `(A)` / split-pencil theorem packet. It is not an
h=3 emptiness theorem, exact SPI count, or finite MCA payment.
