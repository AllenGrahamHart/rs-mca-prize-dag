# Audit

- `W_q` is isotropic for both endpoint forms, hence for every local
  derivative after a projective parameter change. No preferred affine chart
  is used.
- The quotient form is nondegenerate only away from the correction divisor;
  the exception is retained explicitly.
- The Witt bound uses total isotropy `B(U,U)=0`, not merely isotropic
  individual vectors, and is valid in characteristic two as well.
- The source evaluation kernel is exact because the contracted source
  points are distinct and have nonzero weights.
- The rank-one statement is exact. The rank-two statement is intentionally
  the two-valued set `{e-1,e}` and is not promoted to rank `e`.
