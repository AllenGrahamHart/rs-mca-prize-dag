# Frontier

The only independent transverse types are now

```text
m=2: (r,delta)=(2,4),(4,2),(8,1).
```

Every primitive degree-30 outer group is likewise two-transitive with
subdegrees `1,29`, so an `m=2` producer also forces a coarser decomposition.
Unlike the `m=3` route, the known composite-degree routers can return to the
same degree-two block system. The next theorem must exploit the resulting
block-system interaction or the actual quartic/source-star incidence; the
catalogue observation alone does not delete any of these three types.
