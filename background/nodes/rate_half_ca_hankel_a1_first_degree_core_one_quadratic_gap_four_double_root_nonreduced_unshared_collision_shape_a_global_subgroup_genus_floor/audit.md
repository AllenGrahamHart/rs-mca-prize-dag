# Audit

1. The point count uses actual classified-row roots, not the larger
   residual norm degree or a repeated padding multiplicity.
2. Row roots are distinct, so every counted plane point is smooth and has
   one normalization preimage.
3. Multiplicative independence is proved from the pure split fiber; it is
   not inferred merely from unequal coordinate degrees.
4. The characteristic term is removed by the strict integer inequality
   `12N^2mn<2^167`, before the cube-root branch is inverted.
5. The genus floor uses an upper bound on the number of distinct zeros and
   poles, with the inequality in the correct direction.
6. The theorem is prime-field scoped. No generated-extension transport is
   claimed.
7. The exact factor below the arithmetic-genus ceiling is printed with the
   endpoint rounding retained.
   The node is evidence for the critical target and does not change its
   status.
