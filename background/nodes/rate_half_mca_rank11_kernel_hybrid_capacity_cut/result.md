# Result

Taking the better of the ambient and record-support summation orders in
each corank stratum extends the proved kernel-free interval by 131 rows:

```text
previous endpoint: K'=11641
new endpoint:      K'=11772
first open row:    K'=11773
```

The boundary branch pattern is stable: ambient for `d=1,2`, record support
for `d=3,...,9`. The small extension is useful mainly because it identifies
simultaneous cross-stratum saturation as the next mathematical obstruction.
