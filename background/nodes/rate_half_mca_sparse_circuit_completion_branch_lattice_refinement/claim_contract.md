# Claim contract

This node proves a refinement rule for an already valid sparse-circuit case
branch.  It does not choose which leaves to refine or assert that refinement
improves a weighted maximum.

Every child leaf inherits every parent cap.  New source deletion and carrier
caps are intersections, never replacements that can enlarge a cap.

No finite component row, rank alternative, chronology owner, or prize
statement is paid here.
