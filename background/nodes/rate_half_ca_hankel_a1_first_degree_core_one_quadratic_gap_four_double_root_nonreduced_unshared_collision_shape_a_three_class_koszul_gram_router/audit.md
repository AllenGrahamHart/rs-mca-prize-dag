# Audit

1. Each class has more than `n` points, so it spans the full coefficient
   space `V`; this is stronger than using all of `U_0` at once.
2. The full degree-`e` target in `(KGR3)` comes from the independent
   first-degree primitive-kernel coefficients and injective `X`-evaluation.
3. The triple-intersection identity uses the distinctness and coprimality of
   the three center-line forms.
4. The source-frame equations are applied to the same contracted source;
   outside `U_0` its weights vanish on the chosen center line.
5. The Gram matrices may vanish over a finite field. Nonzero diagonal
   weights alone do not make `E^TDE` nonsingular; only Sylvester's lower
   bound is claimed.
6. The common-matrix rank threshold is strict and is rounded correctly in
   `(KGR10)`.
7. The router does not close Shape A.
