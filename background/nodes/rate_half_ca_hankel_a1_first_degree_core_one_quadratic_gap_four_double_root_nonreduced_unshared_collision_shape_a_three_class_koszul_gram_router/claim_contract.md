# Claim contract

- **Claim:** the three Shape-A source classes give the surjective restricted
  Koszul map `(KGR4)` and proportional classwise Gram matrices satisfying
  `(KGR8)--(KGR9)`.
- **Inputs:** the macroscopic rank floor, the first-degree coefficient
  frame/isotropy, the exact source partition, and the dual-MDS row identity.
- **Output:** an exact algebraic target for the remaining macroscopic-rank
  Shape-A interval.
- **Consumer:** `rate_half_band_crossing_location`.
- **Nonclaims:** no Shape-A exclusion and no assertion that `K` is always
  nonzero.
