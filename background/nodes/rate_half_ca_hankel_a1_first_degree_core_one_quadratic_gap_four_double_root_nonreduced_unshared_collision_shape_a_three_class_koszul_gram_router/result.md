# Result

Koszul generator for every degree-`e` parameter form, while its three
classwise source Gram matrices are proportional and have common image in a
single inverse-prolongation space.

The target remains open. The next useful theorem must constrain that inverse
prolongation or show that its common weighted Gram packet is incompatible
