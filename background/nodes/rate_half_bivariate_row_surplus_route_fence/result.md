# Result

The bivariate matrix route survives, but generic overdetermination is fenced.
On the exact `m=1` Hankel failure, every canonical `W` is fully saturated and
the `15 x 6` matrix nevertheless has a one-dimensional kernel.

The next theorem must use an official-scale structural distinction, such as
the already banked `m>1` component/separation exclusions, or prove rank only
for incidence patterns that violate the required `5m/3` intersection cap.

A subsequent bounded `m=2`, `F_97` search found full column rank in all
`1,795,113` sampled bad-overlap pair cases. This is heuristic evidence that
the narrower bad-pattern rank theorem may begin at `m>1`; it is not part of
the proof of this fence.
