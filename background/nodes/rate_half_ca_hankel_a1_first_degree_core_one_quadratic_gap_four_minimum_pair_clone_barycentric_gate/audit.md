# Audit

- `X` uses actual error supports; padded heavy roots are not members of it.
- Rank at most one plus exact core stripping makes every row proportional
  and nonzero.
- Saturated light rows have exactly `e` distinct supported roots, so the
  common parameter form is squarefree.
- The barycentric formula contains the contraction factor `x-s_0`, the RS
  dual multiplier, the row scalar, and the derivative of the difference
  locator.
- The theorem is conditional on sharp pair union, not on an unproved global
  clone classification.
