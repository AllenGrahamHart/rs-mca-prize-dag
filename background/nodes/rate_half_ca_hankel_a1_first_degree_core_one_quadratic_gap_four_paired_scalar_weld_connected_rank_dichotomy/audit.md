# Audit

1. Fiber-neighborhood overlap uses only an upper bound of `n` roots in the
   classified row set; padded roots outside that set can only improve it.
2. Row degree in the selected complement uses at most `m` roots among `Z`,
   not exactly `m`.
3. Pairwise overlap of the fiber neighborhoods plus coverage of every row is
   sufficient for connectivity.
4. The rank dichotomy uses nonzero weld coefficients on nonincidences. No
   division is made at incidence cells.
5. Nullity one does not prove `Krow lambda=0` or the remaining Hankel/source
   equations.
