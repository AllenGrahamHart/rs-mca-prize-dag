# `A=1` quadratic paired scalar-weld connected-rank dichotomy

- **status:** PROVED
- **closure:** the weld kernel is zero- or one-dimensional
- **consumer:** `rate_half_band_crossing_location`

Retain the row set `X`, selected zero-excess fiber set `Z`, and weld matrix
`W` of the paired scalar-weld gate. Let `H` be the bipartite complement
incidence graph: `(x,delta)` is an edge exactly when

```text
P_x(delta)!=0,       F_delta(x)!=0.                 (WRD1)
```

Then `H` is connected in both pair-boundary profiles. Consequently

```text
rank W in {R-1,R},
dim ker W in {1,0}.                                 (WRD2)
```

If `ker W` is nonzero, it is generated by one vector `lambda` with every
coordinate nonzero. Thus the common-biform test has the exact two-stage
form

```text
rank W=R                 => boundary excluded;
rank W=R-1 and Krow lambda=0
                         => the selected row/fiber data have one common
                            biform, unique up to global scalar. (WRD3)
```

No separate full-support search is required.

The connectivity margins are explicit. Any two fiber vertices have at least

```text
extremal: p+3+d_A,
strict:   4+r_A                                        (WRD4)
```

common row neighbors in `H`. Every row vertex has at least

```text
extremal: e+2,
strict:   p-e+3=(e+5)/2                               (WRD5)
```

fiber neighbors in `H`.

## Scope

The theorem does not decide which rank occurs. Rank `R-1` only reaches the
common-biform survivor; the retained Hankel/source identities may still
exclude it.
