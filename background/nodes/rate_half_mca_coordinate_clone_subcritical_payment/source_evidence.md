# Source evidence

The source owner-pencil theorem defines

```text
F_x(gamma,tau)
```

as a bidegree-at-most-`(1,1)` curve and identifies a shared irreducible
`(1,1)` component as the coordinate-clone cell. The new proof applies the
same intersection product used by the source component-free theorem, but
counts points along each shared component and sums by disjoint clone-class
coordinate mass.
