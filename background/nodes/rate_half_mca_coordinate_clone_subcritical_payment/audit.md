# Audit

The proof excludes identically-zero coordinate equations. Such an equation
contains every component and would invalidate the outside-curve intersection
count; the source names it as a fixed-owner coordinate and it must be routed
before this theorem.

Rich points lying on multiple clone components are assigned once. Counting
parameter pairs overcounts challenge slopes and is therefore safe. The
`2n` comparison is a standalone full-budget payment, not permission to sum
this cost with every other first-match cell.

The theorem deliberately leaves a unique class with `c>=m`: there the
denominator `m-c` is nonpositive and the component can carry a positive-
dimensional rich family.
