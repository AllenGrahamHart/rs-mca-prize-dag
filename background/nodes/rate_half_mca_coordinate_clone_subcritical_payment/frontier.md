# Frontier

Attack the unique large clone component. Proportionality of the four
coefficient evaluations

```text
A_0-Q_0r_0,
A_1-Q_1r_0,
B_0-Q_0r_1,
B_1-Q_1r_1
```

on at least `m>k` coordinates should force either a fixed coherent owner, a
global affine line, or a structured correction component assignable to `(S)`.
The exact proportionality scalar varies by coordinate and must not be
silently treated as constant.

One tempting support injection is invalid. On the shared component,
`F_x(gamma,tau)=0` says that the received word meets the rational owner line
at coordinate `x`. For an atom explanation,

```text
Q_tau h + c Lambda = A_tau + gamma B_tau,
```

so even when `Q_tau(x)` is nonzero, `F_x=0` implies
`Q_tau(x)(h-r_gamma)(x)=-c Lambda(x)`, not `h(x)=r_gamma(x)` unless the
selected locator also vanishes. Consequently the component's `c>=m`
automatic curve zeros are not a common agreement support, and denominator
root sets cannot be injected into actual supports to obtain an `n+1` slope
bound. A valid continuation must retain the selected locators, or use the
coefficient proportionality to construct an explicit `(S)`/`(A)` object.
