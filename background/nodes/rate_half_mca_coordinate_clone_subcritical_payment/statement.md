# Coordinate-clone subcritical-class payment

- **status:** PROVED
- **scope:** the coordinate-clone failure of the deployed owner-pencil
  incidence theorem, after its other named shared-component branches are
  routed separately

For an owner pencil, let `F_x(gamma,tau)` be the source bidegree-`(1,1)`
coordinate equation. Assume:

- no `F_x` is identically zero;
- fixed-slope vertical and fixed-owner horizontal components have already
  been routed;
- a coordinate-clone class consists of all coordinates whose nonzero curves
  contain one fixed irreducible bidegree-`(1,1)` component.

For every class `C` of size `2<=c<m`, assign each rich parameter point on
several clone components to exactly one class. Then

```text
N_C (m-c) <= 2(n-c),
N_C <= 2c.
```

Consequently all subcritical clone classes together contribute at most

```text
sum_C N_C <= 2 sum_C c <= 2n = 4194304.
```

This is below both deployed MCA budgets. Since `n<2m`, at most one clone
class has size at least `m`. Every unpaid coordinate-clone exception is
therefore concentrated on one unique large clone component.
