# Audit

1. Singleton pair types cost records, not fixed-pair capacity; each owns
   exactly one by definition.
2. The large-core contradiction shortens exactly `K-2` common coordinates,
   even if the actual intersection is larger.
3. The dimension-two pair count retains the interleaving square-root gate
   and fixed-pair multiplicity.
4. At most four additional pair types are needed because component
   differences span a four-space; no claim is made that one pair adds only
   one dimension.
5. Every selected nonanchor pair is heavy, so two actual records exist.
6. The common support is formed before cancellation and is strictly below
   `K-2`; residual dimension is therefore at least three.
7. Cancellation is replayed directly for exact supports. The narrower
   `K-4922` scope of the older order-32 adapter is not imported silently.
8. The degree floor is the number of anchor-line slopes, `32-2t>=24`, not a
   punctured-domain incidence estimate.
9. No local packet is promoted to a whole-line chronology owner.
