# Audit

The tangent degree argument explicitly branches on whether
`P_y=X^nu H-kappa` is zero. The zero-polynomial case cannot be discarded:
it is exactly the retained `nu=0`, constant-`H` passport. This is why the
node is a reduction rather than a next-to-maximal closure. Local orders in
that passport independently force simple tangent values and squarefree,
complement-disjoint tangent fibers.

The exceptional degree comparison is exact: the right side of the Euler
identity has degree `hp`, while the left has degree
`p+m+p deg(T)+deg(XR')`. The characteristic kills the derivative of the
monic `X^p` leader, so `deg(XR')<=p-1`; this forces `deg T=h-2` rather than
merely bounding it.

The zero-point quotient uses no converse divisibility assumption. The proved
direction is `S | G-lambda Y`; evaluation at zero supplies the additional
root `R(0)`. If that root belonged to `S`, the already-proved tangent-fiber
passport would be contradicted, so it belongs to the residual quadratic.

For the saturation ledger, radical degrees are used deliberately. A simple
root of the outer residual can pull back with arbitrary multiplicity; the
Euler identity puts each distinct nonzero pullback root into squarefree `D`,
while `p-deg rad(R-y)` is exactly the degree consumed in `R'`. The two
different fibers are coprime in both ledgers.

The derivative ledger uses `deg R'=deg(XR')-1=p-m-1`. This one-degree shift
is load-bearing: together with complement capacity it turns the provisional
two-case interval into the exact equality `a_0+a_z=p+m+1`.

If `T=hG-YG'` has no nonzero root, squarefreeness forces the two printed
binomials. The zero split value in the second binomial forces `nu=0`, because
the multiplicative domain cannot contain zero. The packet is constant-size:
five rows and at most 16 norm values per row. It uses
`F_(p^2)=F_p[i]`, valid because every listed characteristic is `3 mod 4`.

The primary checker uses quotient-ring powering. The independent audit uses
the companion matrix of the quadratic and fixed primitive roots of unity.
