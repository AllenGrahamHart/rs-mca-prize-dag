# Audit

The tangent degree argument explicitly branches on whether
`P_y=X^nu H-kappa` is zero. The zero-polynomial case cannot be discarded:
it is exactly the retained `nu=0`, constant-`H` passport. This is why the
node is a reduction rather than a next-to-maximal closure. Local orders in
that passport independently force simple tangent values and squarefree,
complement-disjoint tangent fibers.

If `T=hG-YG'` has no nonzero root, squarefreeness forces the two printed
binomials. The zero split value in the second binomial forces `nu=0`, because
the multiplicative domain cannot contain zero. The packet is constant-size:
five rows and at most 16 norm values per row. It uses
`F_(p^2)=F_p[i]`, valid because every listed characteristic is `3 mod 4`.

The primary checker uses quotient-ring powering. The independent audit uses
the companion matrix of the quadratic and fixed primitive roots of unity.
