# Audit

1. The norm census contains 160 records: five factors times 32 named values.
2. Norm-root completeness is independently replayed by standard-library
   polynomial arithmetic, not inferred from samples.
3. The pole census includes denominator occurrences from the localized
   operator as well as downstream primitive/map/colored packets; it does not
   silently assume downstream cancellations cover an upstream pole.
4. The basis parser accounts for every printed `//` token and accepts only a
   restricted polynomial AST in `t`.
5. The source-forbidden set is removed only after exact root extraction.
6. The overlap is counted explicitly; the router size is 69, not 68 or 70.
7. A router value is an open finite task.  It is not evidence that the fiber
   survives, and this node does not close those fibers.
8. Hostile mutations of one norm record and one pole record are rejected.
