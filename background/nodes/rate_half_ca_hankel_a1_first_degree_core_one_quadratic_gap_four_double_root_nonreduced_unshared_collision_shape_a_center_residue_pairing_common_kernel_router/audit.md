# Audit

1. The large class has two dual-RS parity dimensions, so the radical proof
   retains the affine factor `aX+b`; it does not silently reuse the small
   class argument.
2. Cancelling `X-x_*` uses the proved nonvanishing
   `G(gamma_0,x_*)!=0`.
3. Rank `n` is the rank of the full form on `S_n`, not the rank `r-1` of
   its restriction to `W_X`.
4. The common-kernel parameter `kappa` is not assumed small. At the lower
   rank boundary the theorem instead proves that it must be macroscopically
   large.
5. The toy verifier checks both class lengths, the exact radicals, the
   restricted ranks, and one zero-common-kernel control. That control is a
   consistency test, not official-row evidence.
