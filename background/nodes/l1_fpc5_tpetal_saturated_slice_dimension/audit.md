# Audit

The proof uses four load-bearing hypotheses:

1. pairwise coprimality of the `L_i`, to combine divisibility into
   `Lambda|FB-GW`;
2. saturation `gcd(F,W)=1`, to make the cross-determinant kernel one line;
3. `e>=0`, so the cofactor target has dimension `e`; and
4. `h>d`, so locator projection has zero kernel.

For a nonempty large-source cell surviving `(PF6)`, items 3 and 4 follow
respectively from `r>=0` and the exact list threshold. The other two are
native FPC5 exact-cell guards. The pilot check in
`notes/pilots_20260808/t_petal_lemma/tpetal_dim.py` covered 155 saturated
cells at `t=4,...,8`; it is evidence only and is not used by the proof.
