# Claim contract

## Input

The ten-dimensional residual correction space, empty residual global common
support, actual rank-deficient component incidences, exact supports, and
same-support pair noncontainment.

## Output

For every rank stratum `r=10-d`, one canonical basis chart with explanation
rank `d` and incidence capacity

```text
M_d C(K'-10,d+1).
```

## Nonclaim

The capacities have not yet been summed against the dominant-lane demand,
and no shortening above the proved capacity interval is paid.
