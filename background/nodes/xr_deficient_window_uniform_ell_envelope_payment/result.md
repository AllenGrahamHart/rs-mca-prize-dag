# Result

The next-dimensional higher-`ell` payment is now a proved linear envelope,
not a collection of sampled cutoffs. The exact packed profile is also
available for sharper row-specific optimization beyond that envelope.

The XR target remains open only outside the printed envelope, including the
final high-fiber tails and the one/two-member split-pencil endpoint.

The exact three-fiber boundary fence shows that further optimization of the
same tuple-incidence ledger cannot close that residue. The next useful theorem
must couple the two selected blocks or constrain which large pencil fibers
can be realized simultaneously.
