# Claim contract

The theorem assumes only a ten-dimensional subspace of `F[X]_<K`, distinct
evaluation coordinates, an empty common zero set, and rank ten on the
eleven-sets being counted.

The equality branch is triggered by `q=K-10` **circuit** completions, not by
arbitrary common zeros.  The second branch maximizes over the actual number
of completions before summing deletions.  Its simplified `b=q-1` form is
claimed only for the official rows `K'=14..21`.

No component-density estimate, rank-nine shadow budget, kernel payment,
chronology assignment, or prize closure is part of this node.
