# Audit

1. Division is used only on nonincidence cells. At an incidence, both root
   polynomials vanish and the cell supplies no scalar ratio.
2. Every fiber has a nonincident anchor because `|X|=R>n=deg F_delta`.
3. Padded-heavy roots lie outside the light row set, so they do not create a
   false zero-pattern match on `X times Z`.
4. The converse uses all coefficient blocks of `Krow`, not merely its leading
   block, to reconstruct one biform.
5. Agreement at `R` row points proves fiber-polynomial equality only because
   `R>n`.
6. `W` depends on the chosen anchors, but its full-support kernel condition
   does not: every choice enforces the same per-fiber scalar ratio.
7. The parameter coefficient gate is a consequence after the common biform
   is reconstructed and is not independent evidence.
8. Sparse-row volume alone is not a rank argument.
