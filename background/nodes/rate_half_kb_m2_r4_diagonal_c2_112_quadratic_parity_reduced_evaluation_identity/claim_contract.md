# Claim Contract

| Field | Value |
|---|---|
| scope | any polynomial row `P(w)` and any commutative coefficient ring |
| relation | `R=U^2-VZ` |
| conclusion | exact congruence modulo `(R)` |
| divisions | none |
| route value | lowers the `U` exponent to at most one before expansion |
| excluded | no claim that an instantiated ideal is empty or smaller |
