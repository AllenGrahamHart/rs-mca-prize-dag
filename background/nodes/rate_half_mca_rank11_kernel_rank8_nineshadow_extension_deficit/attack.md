# Attack surface

Try to construct a rank-two quotient with fewer than `C(67474,2)`
independent pairs while respecting both closure caps. Equivalently, seek a
parallel class larger than `K'-1-|cl_S(U)|` or fewer than 67474 nonloops.

Both violate a displayed proof input, so a successful attack identifies
the exact generalized-MDS interface that must be repaired.
