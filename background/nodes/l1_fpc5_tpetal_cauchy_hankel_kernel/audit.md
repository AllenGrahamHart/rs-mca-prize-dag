# Audit

Full row rank uses the saturated primitive-anchor hypothesis through the
proved slice-dimension theorem. A general weighted moment sequence need not
have this rank.

The rational generating function is `chi/Lambda`, where `chi` encodes the
actual arbitrary source-petal labels. It is not replaced by a generic
sequence, an unweighted power-sum sequence, or a common-pencil model.

Hankel structure narrows the flat class but does not itself imply a small
split-divisor intersection. The primitive punctures and background Cauchy
equations remain load-bearing filters, and no maximum-to-mean estimate is
asserted.
