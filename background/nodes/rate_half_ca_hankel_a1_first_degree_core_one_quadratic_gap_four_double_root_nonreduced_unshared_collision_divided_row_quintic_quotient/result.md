# Result

The nonreduced collision carries the same bounded moment quotient in both
deficit profiles: `M(t)u(t)=g_*S_BC(t)` with `deg C<=5`. In the `d_A=1`
case, the center factor missing from `G(t,x_*)` is supplied by `Lambda` in
the Pade syzygy, and the initial relation uses `Lambda_0=Lambda/J_*` and a
cubic heavy-row residual.
