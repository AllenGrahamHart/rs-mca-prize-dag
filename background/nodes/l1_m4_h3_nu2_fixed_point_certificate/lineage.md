# Lineage

The base-field theorem made one odd-sized split fiber Frobenius-stable. The
order-four Frobenius action forces a prime-field root, and the product of the
fiber identifies that root with the fixed split value up to sign. Substitution
into the Belyi normal form turns this geometric fixed point into a scalar
test on the discrete multiplicity triple. Simultaneous input/output scaling
by the fixed value then removes every remaining scalar from the domain
factorization.
