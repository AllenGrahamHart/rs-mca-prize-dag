# Upstream crosswalk - nu=2 fixed-point certificate

This is a base-field-normalized split-pencil census reduction. The remaining
positive `(2,1)` pencil has no domain-coset parameter: its coset is the fixed
split value times the order-`n` subgroup, and every multiplicity passport
must pass one of two printed scalar equations and one scalar-free divisibility
into `W^n-1`.

An upstream `(A)` packet can use the equation as a mandatory first filter in
an exact SPI or exchange-degree ledger. It is not an exact SPI count, a
complete passport classification, or an MCA row payment.
