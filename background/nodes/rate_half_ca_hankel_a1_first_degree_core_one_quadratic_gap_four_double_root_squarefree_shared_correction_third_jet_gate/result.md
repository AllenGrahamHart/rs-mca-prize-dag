# Result

At a squarefree shared root,

```text
F_i=z^2(kappa_tau x_*^i+O(z)),
D_1|F_i for all i       iff kappa_tau=0.
```

Thus the shared branch is reduced to one exact third-jet decision. If the
jet vanishes, the cubic quotient extends and the local Smith type is `[3]`;
otherwise the canonical divided-row image has exact order two.
