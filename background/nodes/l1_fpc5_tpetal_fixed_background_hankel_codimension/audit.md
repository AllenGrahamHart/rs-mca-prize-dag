# Audit

The rank statement is conditional only on nonemptiness through an actual
primitive monic member; it does not assert that every formal fixed-`R` cell
is nonempty.

The fixed-`R` chart includes `R` in the CRT modulus with label zero. Merely
testing `B(y)=0` after constructing the petal-only chart gives the same
locus but hides its exact `ell-1` Hankel codimension.

The incidence identity weights a member with extra background zeros by
`binom(|R_G|,u)`. It cannot be read as an unweighted equality or as a
payment. Lexicographic assignment removes duplication but destroys the
complete linear fixed-`R` chart, so a counting theorem must respect that
filter or use a weighted aggregate argument.
