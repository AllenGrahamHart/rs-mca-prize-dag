# Audit

1. The residual bundle is on the normalized locator curve, not on `G=0`.
2. `P_F` is compared only after the same fixed contact normalization used in
   the regular-factor theorem; raw polynomial bidegrees are not conflated.
3. `G_X` is nonzero because the pure fiber is squarefree. `G_t` is nonzero
   independently because every classified row has distinct parameter roots.
4. One pure fiber already suffices to disqualify each raw derivative: failure
   at even one mandatory point prevents descent through the full divisor.
5. The theorem does not rule out a nontrivial linear or higher source
   combination whose coefficients restore all mandatory zeros.
6. No computation, smoothness assumption, or generic-gonality claim enters.
