This is a semantic/compiler theorem. It closes the ambiguity in the predicate
slot and the certificate-selection multiplicity; it does not solve the
balanced-core census.

The effective locator dimension is `K=k+1` on the active MCA source route,
while the Reed--Solomon code dimension remains `k`. The schema records both.
Using `K=k` would change the depth from `67471` to `67472` and is rejected by
the verifier.

The canonical certificate includes the affine slope, so a one-per-slope
selection is injective without claiming that all raw support witnesses are
distinct. Raw witness multiplicities are deliberately not charged.
