# Audit

The primary checker exhausts the exact `x` interval for every displayed
last-paid and first-unpaid support wall, reconstructs the complete recursive
direction envelope, and checks the first-residual interval arithmetic.

The independent checker uses falling-product recurrences instead of direct
products, checks support monotonicity on small exact models, and reconstructs
the recursive frontier from the supplier contract.  Source statements and
the recursive source contract are hash-pinned.  Both checks use constant
memory and bounded integer arithmetic under the tiny RAMguard profile.
