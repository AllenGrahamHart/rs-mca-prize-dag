# Audit

The verifier checks the regression contract, the two independent extremal
gates, the exact residual intervals supplied by the proved occupancy
compiler, the exhaustive two-branch lifted-rank control, and the two exact
full-lift compiler ceilings.  The full-lift extension has MDS-sharp higher
generalized weights; this is a route localization, not a payment.

Historical rank/support scans are not accepted as proofs.  The target
cannot return to `PROVED` until every printed interval is paid.
