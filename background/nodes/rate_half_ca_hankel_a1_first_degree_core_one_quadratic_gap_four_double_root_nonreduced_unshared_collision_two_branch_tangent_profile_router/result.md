# Result

The two companion-bearing shapes with two collision branches, B and D, no
longer support all three local profiles. Profile `[4]` is impossible for
them. Their complete local uncertainty is one scalar equation: cancellation
of the two normalized branch tangents.

This does not close either shape. It separates the next attack into a
generic noncancelling `[1,3]` arm and an exceptional tangent-cancelling
`[2,2]` arm. Shapes A and C remain compatible with all three profiles.
