# Audit

1. The row integer called `p` elsewhere is not the field characteristic;
   this node writes the characteristic as `P`.
2. Row saturation is factorwise: each classified row contributes exactly
   two distinct companion roots in `Gamma`, with no specialization of
   `Q(-,x)` equal to zero.
3. The seven-defect count uses only `deg_X Q<=3`; it does not assume that
   every slope is a clean split fiber.
4. Dividing the three alternating minors by `X-Y` before forming `K_Q` is
   essential. Omitting the division changes both the degree and point
   count.
5. A fixed ordered row pair has at most two common slopes because both row
   polynomials are nonzero quadratics. This is why six ordered pairs per
   full triple become at least three distinct pairs.
6. Absolute irreducibility is proved from the large rational point set; it
   is not inferred merely from irreducibility over `F_P(X)`.
7. The cyclic orientation images need not be assumed distinct. Each
   distinct image has the stated lower count; if there are two, Frobenius
   exchange is defeated by the intersection bound.
8. The published theorem is invoked only after an explicit VM-admissibility
   hypothesis. No claim is made that every component is automatically
   admissible.
9. All point transformations used in the definition of VM-admissibility
   preserve `H^2`.
10. The strict numerical comparisons are certified by exact integer cubes,
    not floating-point approximations.
