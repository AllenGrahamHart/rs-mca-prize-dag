# Result

The ordinary `(2,3)` companions in shapes B and D can no longer survive by
a generic low-degree coincidence curve. Their exact row saturation forces
too many points in the official order-`2^41` subgroup for any component to
which the published subgroup-curve theorem applies.

The remaining task is finite and algebraic: classify the symmetric
determinantal components for which every swap/inversion normalization fails
one of the two coordinate-corner hypotheses. Excluding those components
would eliminate all `(2,3)` companions and therefore shapes B and D.
