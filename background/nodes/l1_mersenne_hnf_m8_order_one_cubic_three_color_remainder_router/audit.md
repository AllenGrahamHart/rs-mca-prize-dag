# Audit

The cyclic rotation is a symmetry of the necessary value-remainder system,
not of a fixed actual rootwise Frobenius assignment. It is used only to
transfer unit or retained verdicts between algebraically equivalent packets.

The three fiber resultants enforce that every named color is used. Exact
multiplicities require subresultant equalities and the next nonvanishing
subresultant; bare resultant vanishing is insufficient.

The system deliberately omits the assignment-preserving Frobenius
composition, full cyclotomic divisibility, and inner lift. A unit ideal is a
valid exclusion, while a retained component is only a false-positive-prone
candidate requiring those stronger tests.
