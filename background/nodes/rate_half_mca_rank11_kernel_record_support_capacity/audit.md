# Audit

1. Every counted basis lies in the record's exact support.
2. Every extension coordinate lies in both that support and the common-zero
   flat; dropping the support restriction only enlarges the cap.
3. The generalized-MDS subtraction is `(K'-d)-(10-d)=K'-10`.
4. Each eleven-set is divided by at least `d+2` actual bases.
5. The bound is per record and uses no `M_d` factor.
