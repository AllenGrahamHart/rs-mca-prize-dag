# Claim contract

## Input

correction space, with empty global common zero set and evaluation corank
`1<=d<=9` on the counted eleven-subsets.

## Output

```text
floor(C(m',10-d) C(K'-10,d+1)/(d+2)).
```

## Nonclaim

No multi-record synchronization, cross-corank compatibility, complete
kernel-lane payment, rank-eight payment, or prize closure is asserted.
