# Audit

The conic is a quotient coordinate, not a proof of rationality of the whole
order-one curve. The pullback `c^2-zc+1=0` remains and can carry a nontrivial
quadratic extension. It must not be dropped in an elimination.

The parameterization (OCR7) is one affine chart. The second point over
`z=-1`, namely `(-1,-6)`, is `t=infinity`; the base point `(-1,6)` is the
tangent specialization `t=23/7`. The denominator-zero values are projective
conic points. A contributor computation must cover all of these charts
explicitly and intersect them with the original affine variables rather than
silently dropping or adding points.

The formula concerns only `h=7`. It does not transport to `Psi_15`, and it
does not make a conic point an outer survivor. All reciprocal, Frobenius,
torsion, cyclotomic, and inner conditions remain load-bearing.
