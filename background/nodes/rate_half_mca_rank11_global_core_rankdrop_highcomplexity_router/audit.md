# Audit

The proof was checked at the following semantic boundaries.

1. The line-global core is cancelled once for the complete family; no
   record-local core sum is used.
2. The dense pair descends because the global core lies in the intersection
   of two dense-pair maximal supports.
3. Division preserves, rather than lowers, deviation dimension. The paid
   branch is an honest case split on the pre-existing dimension `r`.
4. The rank-at-most-nine payments are uniform in the shortened code
   dimension. Their only variable endpoint has a one-turn ratio, so both
   endpoints are checked.
5. The rank-ten anchor intersection is empty on the shortened domain before
   support-collapsed extraction is invoked.
6. A denominator root on a deleted coordinate is retained as `(E)` after
   lift; it is not silently discarded.
7. Two-cover and near-sunflower thresholds lift by exact add-back of `2c`
   and `c`, respectively.
8. The high-complexity output is deliberately named `(H_C)`, not `(S)`.
   No deployed-domain spread abundance theorem is claimed on an arbitrary
   punctured domain.

All arithmetic replay is exact integer arithmetic. No Modal computation is
used.
