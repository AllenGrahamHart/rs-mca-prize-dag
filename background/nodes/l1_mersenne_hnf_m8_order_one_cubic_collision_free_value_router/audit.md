# Audit

The cyclic scaling is a symmetry of the necessary value-resultant system,
not of a fixed actual Frobenius assignment. Retained points must be checked
with the unscaled pointwise equation before any outer conclusion.

The squarefree condition on `V_E` is essential: without it, (CFV3) covers
only collision-free values and must not be used for a repeated-color
profile.

The value identity does not imply that `E(x)=x^(p+1)` for corresponding
roots. It is an exclusion interface only; a nonunit component is not an
outer survivor.
