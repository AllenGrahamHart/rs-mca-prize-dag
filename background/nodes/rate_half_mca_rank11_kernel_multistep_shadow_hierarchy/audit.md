# Audit

The primary verifier reconstructs all 28 symbolic rows, freezes the six new
triple constants, checks the independent-set recurrence, and runs hostile
mutations.  The independent verifier derives the shadow, extension, and
target multiplicities from separate recurrences over every `(t,d)` pair.

The theorem uses only integer binomial counts.  No floating-point result is
part of the proof or status promotion.
