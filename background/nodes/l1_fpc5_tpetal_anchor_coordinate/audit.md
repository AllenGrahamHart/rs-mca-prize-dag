# Audit

The affine bijection uses monicity twice: it makes the chart a codimension-one
affine space, and it kills the one scalar anchor direction in the linear
kernel. The owner identity additionally uses squarefreeness of `F`,
primitivity `gcd(F,W)=1`, and automatic petal disjointness. All are exact
FPC5 contributor guards.

No finite-field enumeration or dimension heuristic is used.
