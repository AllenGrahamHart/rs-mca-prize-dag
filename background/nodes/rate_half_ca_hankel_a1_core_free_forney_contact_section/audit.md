# Audit

1. The half-distance matrix has exactly `rho` recurrence rows, so the last
   cancelled coefficient is `u^(2rho-1)` and the contact order is `2rho`.
2. The strict `A=3` order `2rho+2` is not imported.
3. If the low numerator vanished, the low coefficients and the recurrence
   rows together would kill all `2rho` available moments.
4. The `e+2` clean fibres are more than the parameter degree of any repeated
   factor, which proves reducedness.
5. Core-freeness is essential for ruling out an `X`-only component.
