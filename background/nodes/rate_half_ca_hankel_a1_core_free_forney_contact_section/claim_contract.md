# Claim contract

- **Claim:** every failing core-free half-distance `A=1` profile carries the
  nonzero contact section `(A1F5)`.
- **Dependency:** the half-distance `A=1` core slope-slack ledger.
- **Output:** a section of `O_C(-rho-1,e+1)` of degree `Delta=rho-e`.
- **Consumer:** the core-free pole-slack exclusion.
- **Nonclaim:** no assertion is made for fixed-core profiles or for
  componentwise nonvanishing.
- **Falsifier:** a missing recurrence row, a zero canonical numerator, a
  repeated component compatible with the `e+2` clean fibres, or the wrong
  contact order in `(A1F4)`.
- **Replay:** run `verify.py` and `verify_audit.py` in this node directory
  under `tools/ramguard tiny --`.
