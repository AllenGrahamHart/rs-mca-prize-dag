# Result

The apparent `p^6` KoalaBear scope obstruction is removed for the affine-pair
subproblem: its order-`2^21` subgroup, cube preimage, and affine coefficients
all lie in the prime subfield, so the extension-ambient count is literally
the Mattarei prime-field count. The same transport is not available for the
Mersenne-31 quartic domain.
