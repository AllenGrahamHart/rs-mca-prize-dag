# Claim contract

- **Input:** the actual branch partition used by `imgfib`.
- **Output:** proof that every branch has a direct proved interface or one of
  the two exact red petal owners, so LIST has no Conjecture-F call.
- **Exact red owners:** `l1_full_petal_fpc5_payment` for the full-petal FPC5
  complement; `l1_mixed_petal_amplification` for mixed/partial petals.
- **Must preserve:** the distinction between source-petal count `M` and
  touched-petal count `t`, first ownership, and quotient/profile charging.
- **Nonclaim:** either red owner is proved; the full Pade section is linear;
  Conjecture F is unnecessary to SPI or to a future newly wired LIST route.
