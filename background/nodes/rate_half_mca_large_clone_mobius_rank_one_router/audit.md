# Audit

The common component gives proportional coordinate equations, not common
agreement supports. The proof never asserts that a clone coordinate is a
root of an explanation locator.

The cancellation is in the projective slope parameter, not in `X`. It is
valid only after root counting proves that the numerator also has the same
slope factor. This is automatic for `|C|>=m+1`, but at `|C|=m` the surviving
degree-`m` polynomial can be `mu Lambda_C`; that boundary is retained.

Rank one refers to the polynomial span of the two slope coefficients of
`Qhat`, not their pointwise evaluations. Pointwise proportionality would not
justify a global factor.

The fixed-owner conclusion counts only rational atom points. The unique
zero of the scalar slope factor has zero pulled-back denominator and remains
a pure-locator/degenerate parameter. No denominator-root set is injected
into a support.

The proof is field-general. Irreducibility of `F_*` is used exactly through
`ad-bc!=0`; no algebraic closure or characteristic restriction is hidden.
