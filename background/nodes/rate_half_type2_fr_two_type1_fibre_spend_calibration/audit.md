# Audit

1. The fibre partition uses the full projective line, including the point at
   infinity. It follows from one-dimensional kernels of nonzero coordinate
   evaluations; it is not an empirical regularity assumption.
2. Inequality `(TFC2)` uses `g!=gamma`. In the two-type-1 application, every
   type-2 slope is distinct from both selected type-1 slopes.
3. No cleanliness assumption is used for the type-2 root set. The proof uses
   only `|S_gamma|<=rho`; smaller sets improve the spend.
4. The equality `T<=9m/2` is an upper bound supplied by this ledger, not a
   construction attaining it and not a lower bound on the true numerator.
5. The `25m/4` threshold is exact for the lower bound
   `p>=n_1+n_2-rho`. A pencil might have larger actual spend even when its
   fibre sum is smaller, so no converse about realizable pencils is claimed.
6. The calculation is at the worst NEWCAP endpoint `a=7m-1`. Other support
   sizes require their own floor arithmetic.
7. The active Round-32 canonical pilot was inspected only for coordination.
   Its dirty worktree is not a proof source for this node.
8. No critical status, safe crossing, adjacent unsafe witness, or prize
   ledger value changes.
