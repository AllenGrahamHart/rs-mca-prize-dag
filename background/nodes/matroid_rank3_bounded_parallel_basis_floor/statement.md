# Rank-three bounded-parallel basis floor

Let `M` be a loopless rank-three matroid on `m>=3` elements.  Suppose every
parallel class has size at most `a`, where `a>=1`.  If `b(M)` is the number
of unordered bases, then

```text
2 b(M) >= (m-1)(m-1-a).                         (BP)
```

When `a` divides `m-1` and `m-1>=2a`, equality is attained by taking one
coloop together with a rank-two matroid on the other `m-1` elements whose
parallel classes all have size `a`.
