# Audit

1. The source code has dimension `d+1`; repository dimension `K` therefore
   means `d=K-1`, not `d=K` and not a padded rate.
2. The source exceptional set is the finite set `z in F_q`. No `q+1`
   projective denominator is introduced.
3. The noncontainment test and the close-codeword test use the same support.
4. The imported error term is `(ell^7/3)(rho*n)^2`, quadratic in `n` after
   fixing the Johnson gap. The sharper BCHKS25 linear expression remains
   outside this node.
5. The source proof's Claim 5.7 citation is version-sensitive; the pinned
   upstream audit reconciles it with BCIKS20 Claim 5.6/(5.10). This is a
   citation correction, not an added hypothesis.
6. The theorem is a preprint theorem with a public proof. `PROVED` here means
   proof-audited mathematical import, not journal peer-review status.
