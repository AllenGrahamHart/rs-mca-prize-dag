# Audit

1. The argument uses the actual residual row `K'=11`; it does not transport
   the effective `k+1` lattice envelope into the RS evaluation space.
2. Rank-nullity gives a two-dimensional kernel on `B`, and the ambient
   vanishing ideal on nine points also has dimension two. This proves
   equality rather than a guessed locator containment.
3. The hyperplane functional factors through `ev_B` because it annihilates
   the complete ambient kernel `L_B RS_{<2}`.
4. The circuit is fixed by `B` and `V'`; it does not depend on the extension
   pair or the record owner.
5. Empty global common support and two distinct fixed-chart slopes exclude
   circuit size one. Empty support is not silently strengthened to a
   globally loopless evaluation matroid.
6. A nine-shadow has rank eight iff it retains the unique circuit. This
   yields `C(11-c,2)`, not `C(9-c,2)`.
7. All sizes `2..9` are realized by explicit hyperplanes, so the table is a
   classification and a route fence, not evidence that one size is generic.
8. The eight-petal witness occupies `c=9` and must survive every later local
   capacity proposal.
