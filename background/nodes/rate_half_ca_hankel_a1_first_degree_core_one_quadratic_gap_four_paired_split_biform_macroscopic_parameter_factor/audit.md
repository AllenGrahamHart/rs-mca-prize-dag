# Audit

1. Both specialization directions are nonzero. A zero parameter fiber
   would force all `R` classified rows into one support of size at most
   `rho`, while `R>rho`.
2. The content factor has no root on the classified row set because every
   row polynomial has exact positive parameter degree.
3. The incidence inequality closes with equality against `R sum m_j=RM`;
   factorwise saturation is not inferred from row surplus alone.
4. Exact degree and squarefreeness on each clean fiber force every factor
   to retain its full `X`-degree and split there; no generic-specialization
   assumption is used.
5. The large-factor bound uses the official parity `M=e-2` odd and the
   exact identity `N=(3M-1)/2`.
6. Strict inequality `m_j<3e/c` is used only for the contradiction; its
   negation gives the ceiling in `(PMF4)`.
7. The theorem rules out bounded-degree factor mechanisms but does not
   exclude one or more macroscopic factors.
