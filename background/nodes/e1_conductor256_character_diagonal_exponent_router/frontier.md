# Frontier

For each `mu in {1,2,3,4}` and each nonempty fixed-root collision family:

1. choose one exact anchor vector;
2. certify outward intervals for the 63 values `|kappa_j|`;
3. derive the integer ellipsoid and coordinate box from `(CER7)--(CER10)`;
4. project the branch-and-bound count and peak memory before launching;
5. branch in conjugate-paired real Fourier coordinates without quotienting
   fixed-root owners;
6. construct `u` and `u^(-1)` exactly in `Z[X]/(X^128+1)` and apply the
   cofactor coefficient box before multiplying the anchor;
7. retain only exact profile-`(3,6,S=18)` vectors and count torsion orbits.

The output must sum the four cofactor counts and compare the result with 367.
Even a successful maximum-weight count does not close the pair budget until
the lower-weight profiles are included in the exact weighted ledger.

No generic support census, floating-point acceptance test, or unbounded
rank-63 enumeration is an admissible successor.
