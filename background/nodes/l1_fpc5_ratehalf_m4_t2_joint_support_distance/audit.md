# Audit

1. Shared core and background roots are disjoint and are charged to the same
   determinant only after the two ratio identities are checked.
2. Candidate-wise cofactor primitivity is essential: without it,
   `Delta=0` can arise from different polynomial common multipliers.
3. Monicity converts scalar-proportional locator images into equality.
4. The packing uses combined supports of variable size and lower-bounds each
   size by `ell+2s`; it does not assume all background sets have size `s`.
5. The packing cap has a dimension-dependent exponent and is not presented
   as a prize close.
