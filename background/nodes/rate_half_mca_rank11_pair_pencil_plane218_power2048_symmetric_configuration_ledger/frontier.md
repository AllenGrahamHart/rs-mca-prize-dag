# Frontier

The degree-2048 branch is no longer a loose near-saturated line bank. It is
an exact symmetric configuration whose line directions are 218 distinct
members of `mu_1024`, together with a 72-slot global quotient-fiber defect.

A closing result may now use either:

1. a nonexistence theorem for a `218_15` configuration represented with
   distinct directions in this fixed multiplicative subgroup; or
2. a quotient-owner theorem that prices the 146 or more completely
   saturated fibers and the point with at most four incident defects.

Abstract configuration counting alone is not asserted to decide the branch,
and the characteristic-zero Hirzebruch inequality is still not imported.
