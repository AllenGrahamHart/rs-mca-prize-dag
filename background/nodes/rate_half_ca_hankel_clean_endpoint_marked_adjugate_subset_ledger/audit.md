# Audit

1. `L=D_x0 M` is a row contraction of the full rectangular pencil; its
   generic rank is proved, not inherited automatically from a square block.
2. The image test uses both shifted left-kernel vectors and the nonzero
   polynomial `Q(t;x_0)=A_0S`.
3. Parameter infinity is chosen outside the marked rank-drop set only after
   generic rank is established; this is one more finite avoidance compatible
   with the earlier normalizations.
4. The adjugate scalar has exact degree `2m-1`, not merely an upper bound.
5. The compound-matrix calculation retains multiplicity and proves
   `D=Delta Q(-;x_0)`; a root-set argument alone would not suffice.
6. The adjugate indexing deletes row `j` and column `i`; symmetry makes the
   displayed product insensitive to swapping them, while the cofactor sign
   remains explicit.
7. Only the corner minors are automatically nonzero ordinary Vandermondes.
   Interior generalized minors and every weighted subset sum may vanish.
8. `(MAS6)` counts distinct supported parameters, not multiplicities of
   roots of `D`.
9. The exact `m=1`, `F_17` fence independently replays the boundary case:
   both the marked rank drop and the marked fibre root occur at infinity.
   It is audit evidence only, not an official-scale premise.
