# Audit

1. The rank input is the first-degree marked-source coefficient chain, with
   the same `e=(2^39+1)/3` used by Shape A. The earlier maximal-component
   theorem uses a different `e` and is deliberately not an input.
2. The two-slope theorem explicitly identifies this primitive locator as
   `Qbar` in the quadratic branch.
3. Shape A has `d_A=1`, so there is no fourth exceptional source class.
4. The three multipliers in `(6)` are fixed by the class and are nonzero;
   only their dimension upper bound is used.
5. Evaluation on `U_0` preserves `sr(G)` because `R>deg_X G`, and preserves
   `sr(Qbar)` because `R>3e-2`.
6. The varying nonzero scalars `eta_x` and `L_U0'(x)` do not affect spans.
7. The conclusion is a lower rank bound, not a Shape-A exclusion.
