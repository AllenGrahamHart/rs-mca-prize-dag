# Audit

- The index decomposition is `i=s+ra`, not `i=a+4s`; this is what turns a
  complete frequency residue class into one local equation per quotient
  fiber.
- The outer Fourier matrix is invertible because the characteristic does not
  divide `r`: exact order `4r` in the multiplicative group already implies
  this.
- Linear independence of `1` and `omega` over the whole field is not used.
  Only the finite difference set `{0,+1,-1}` is relevant, and an element of
  exact order four cannot be a ratio of two nonzero such differences.
- The event ratio is computed before primitive deletion. After deletion the
  joint numerator is exactly zero, not merely smaller.
- Complete spectral residue classes are essential to the localization. The
  official DLI bands are truncated prefixes, so the theorem is a route
  boundary and owner check, not a transport theorem.
