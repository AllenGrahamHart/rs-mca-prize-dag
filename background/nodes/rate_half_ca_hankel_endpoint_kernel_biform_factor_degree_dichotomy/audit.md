# Audit

1. Domain degree is taken after choosing primitive polynomial factor
   representatives; multiplication cannot cancel the leading domain term.
2. A specialization `Q_j(gamma,X)` cannot vanish identically: that would
   produce a parameter-linear factor and a zero image of the proved
   rational-normal kernel map.
3. A specialization `Q_j(Z,x)` cannot vanish identically because the
   complete kernel polynomial is nonzero at every domain point.
4. Root overlaps between different factors are harmless: `u_gamma` is
   bounded above by the sum of factor incidences.
5. The proof uses `O<=m-1) in the generous direction. A smaller omission
   count only strengthens the dichotomy.
6. The dominant-factor bound is a necessary profile restriction, not a
   realizability or endpoint-closure claim.
