# Audit

1. Exact root multiplicity two is used to isolate a quadratic Hensel
   factor; the complementary factor is not silently included.
2. `b` has exact order two because `kappa_2` is nonzero.
3. The trace estimate is checked separately for two unramified branches
   and one tame ramified branch.
4. Corank at least two, rather than divisor length, forces `a(0)=0`.
5. The determinant has a unique order-four leading term `b^2`.
6. Explicit two-branch and ramified fixtures realize both residual Smith
   profiles, so neither is promoted to an exclusion.
