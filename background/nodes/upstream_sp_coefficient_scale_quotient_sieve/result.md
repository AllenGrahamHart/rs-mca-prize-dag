# Result

The nonconstant X4 branch can be sieved before incidence counting.  Every
pair with a common coefficient scale descends uniquely and belongs to the
quotient bucket.  The direct primitive SP target therefore needs only
coefficient-primitive split pairs.  On the official dyadic domain, every
pair with odd side width or odd locator-difference degree is automatically in
that primitive residue; the even-even branch is recursively quotient-sieved.
