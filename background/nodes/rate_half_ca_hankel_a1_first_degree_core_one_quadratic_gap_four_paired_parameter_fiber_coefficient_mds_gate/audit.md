# Audit

1. `m` is the parameter degree and `n` the domain degree; the proof does not
   transpose these labels silently.
2. The slope set is a subset of distinct zero-excess slopes, so every
   barycentric denominator `L_Z'(delta)` is nonzero.
3. Positive-deficit fibers are retained through their padded-heavy roots.
   Omitting them would give the weaker clean-fiber matrix only.
4. Monicity identifies the full-support vector with the leading
   `X`-coefficient of the same biform, not an independently chosen scaling.
5. The parity matrix is necessary. Its large row count alone does not imply
   full rank or exclude a kernel.
6. The fixed-domain and fixed-parameter gates constrain one common biform;
   satisfying either matrix separately is not a realizability certificate.
