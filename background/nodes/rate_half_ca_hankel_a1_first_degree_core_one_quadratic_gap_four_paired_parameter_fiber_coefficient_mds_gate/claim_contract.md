# Claim contract

- **Proposition:** the monic root-coefficient profiles of all selected
  zero-excess parameter fibers share one low-degree denominator and one
  explicit full-support dual-GRS kernel vector.
- **Quantifier:** every biform and every subset of fibers satisfying the
  paired padded-fiber factorization.
- **Dependency:** the paired zero-excess padded-fiber factorization.
- **Falsifier:** a valid selected fiber set for which a scaled coefficient
  vector fails the printed RS parity checks.
- **Nonclaim:** no matrix-rank theorem, pair-boundary exclusion, or critical
  status change.
