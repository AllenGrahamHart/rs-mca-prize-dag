# Attack

A counterexample must exhibit one of the following:

- a zero normal despite `K=s=2`;
- two proportional incident normals despite the `67473`-outside-one-span
  MDS bound;
- an incident projective set contained in a line despite full incident
  rank;
- more than `C(m-1,3)` collinear triples in a noncollinear `m`-point set;
- two parameter points determined by one independent affine-hyperplane
  triple.

The cap may be sharpened only by improving the extremal collinear-triple
bound using structure absent from the present hypotheses.
