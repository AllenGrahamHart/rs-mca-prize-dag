# Frontier

The official nonzero affine-reflection class is now numerically exact:
one fixed pencil has at most `1154` disjoint fibers. The unresolved issue is
not another cyclotomic count but cross-packet ownership.

The bounded exception-SPI normal form constructs a pencil from a selected
twenty-record packet. Different packets from the same heavy pair type are not
yet proved to return the same `c`, a bounded list of constants, or even the
same pencil class. Therefore neither

```text
58361*1154=67348594
```

nor any similar aggregate charge is currently authorized.

The next useful theorem should prove one of:

1. a canonical fixed pencil for each chronology-owned pair type;
2. a bounded-multiplicity packet-to-pencil assignment with disjoint currency;
3. a collision theorem showing that too many varying packet pencils force a
   common locator, Wronskian factor, or already-priced quotient-periodic class.

The `c=0` antipodal case must be sent to the cyclic/dihedral periodic bucket,
not hidden inside this cap.
