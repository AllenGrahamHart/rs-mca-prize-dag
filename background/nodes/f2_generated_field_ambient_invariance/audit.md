# Audit

1. The target counts distinct blocks and block families, not polynomial
   presentations. Scaling is a bijection on both; polynomial substitution is
   included only to preserve the mixed-pullback presentation.
2. The coset representative need not lie in the generated field. The proof
   uses only that each `g^j` is nonzero in the ambient field.
3. No Frobenius antipodal identity is used. The result applies equally to the
   plus direct-sum and minus coupled-code descriptions.
4. Ambient invariance of the final combinatorial/kernel object does not imply
   invariance of `(O1)`, whose normalization and averaging space depend on
   `e`. The explicit non-generating counterexample remains valid.
5. The theorem does not identify these syndrome fibers with upstream's
   first-match residual family `P_Q(z)`.
