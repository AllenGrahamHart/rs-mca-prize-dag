# Result

The residual rank wall is now an explicit interpolation problem. Highest
clone columns measure the failure of the symmetric-root coefficient data
`x^i h_j(x)` to interpolate from `4m+1` pivot points; lower deficiency clones
remain as direct monomial columns.

This explains the controls without a generic-rank heuristic. On the `m=1`
failure, every coefficient datum interpolates across the sixth point, so the
one residual column is zero. The next falsification target is whether one
fixed coefficient block, or a small collection of them, always has full
column rank on bad `m=2` patterns.
