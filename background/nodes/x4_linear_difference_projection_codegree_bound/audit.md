# Audit

1. The intersection bound fixes one side of the incidence.  It does not say
   that arbitrary removed sets from different added sets meet in at most one
   point.
2. The count is a projection codegree, not the number of linear polynomials
   `aX+b` and not the total number of records.
3. The official `1024` uses the local base-row tuple `N=2^41` and
   `128<=log2(q)<256`.  A quotient row must replay its own parameters.
4. The lower bound `t_XR>=2^31` uses only binomial symmetry, unimodality, and
   `binom(N,m)>=(N/m)^m`; it does not use a floating entropy estimate.
5. First-owner stripping preserves the theorem because it only deletes
   incidences.  It supplies no projection-size bound.
