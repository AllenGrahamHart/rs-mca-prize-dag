# Audit

The collision argument retains the assignment `E(x)=x^(p+1)`. Merely
knowing `E(x) in mu_8` would not justify the affine Frobenius map in the
`C=0` branch.

The marked-point permutation follows from six distinct reduced roots versus
a degree-three identity. The removed root is used only as the third marked
point; it is not incorrectly assigned the same quadratic interpolant.

All exceptional divisions are guarded: `S=0` is the retained branch,
`A!=0` by quadratic degree, `K!=0` in the split-value identity, `d!=0`, and
`r=1` is inconsistent with the first derivative equation.

Equation (QCR3) is necessary only for the two-antipodal-pair chamber. It
does not apply to collision-free or one-repeat quadratic packets and is not
an emptiness certificate by itself.
