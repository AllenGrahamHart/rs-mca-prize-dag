# Audit

1. The row hypothesis includes exact degree and nonvanishing, not only the
   presence of `m` prescribed roots.
2. A common parameter factor must contribute all of its degree inside
   `Gamma`; otherwise a degree-`m` row cannot have `m` roots there. Its roots
   then produce forbidden identically zero fibers.
3. Distinct projective coefficient types give linearly independent pencil
   members, so a shared root is a common root of the primitive pair.
4. The numerical threshold is strict: `4(e-2)>3e` begins at `e=9`. The
   `e=7` fence has four types and is not contradicted.
5. A globally constant projective `B` ratio is handled separately as tensor
   rank one; it also creates zero parameter fibers.
6. The conclusion concerns separation rank of the biform, not matrix rank of
   every `K_all` incidence profile.
