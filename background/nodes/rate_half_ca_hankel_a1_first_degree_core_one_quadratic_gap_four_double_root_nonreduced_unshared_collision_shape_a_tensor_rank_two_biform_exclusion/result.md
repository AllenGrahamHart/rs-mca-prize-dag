# Result

The exact `e=7` kernel identifies a real low-rank exception, but that
mechanism cannot persist to the official regime. The seven-row surplus

```text
R-3n=7
```

forces more projective row types than a rank-two parameter pencil can fit
inside `3e` slopes. Any official Shape-A survivor therefore has coefficient
tensor rank at least three.

The remaining rank problem is correspondingly narrower: classify or exclude
high-separation-rank kernels using spread, collision, or source/Hankel
structure.
