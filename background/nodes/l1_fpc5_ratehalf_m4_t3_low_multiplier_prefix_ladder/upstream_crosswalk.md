# Upstream crosswalk

This is a concrete ladder/tower-transfer input for upstream `(Q)` flatness.
At multiplier degree `e`, the FPC5 atom has `Q_0^(e-a)` targets, but each
target fixes `e-a` more locator-prefix coefficients than the bottom cell.
The average-scale loss and gain cancel exactly in `(PL5)`.

The portable missing statement is therefore not an unstructured union bound.
It is prefix max-to-mean control uniform along this exact depth/target ladder.
The high-multiplier range remains a BC split-in-subspace instance rather than
an ordinary prefix cell.
