# Claim contract

- **Claim:** equations `(RWF1)--(RWF11)`, including the exact first
  nonzero residual parity and the use of one projective weld vector for all
  fibers.
- **Dependencies:** the coefficient-MDS row normalization, connected
  scalar-weld dichotomy, all-excess residual-fiber factorization, and
  shape-A norm concentration.
- **Nonclaims:** no rank bound for the stacked matrix, no bound on
  `sum q_delta`, no Shape-A exclusion, and no adjacent-row movement.
- **Falsifier:** a padded root inside `U_0`, an incorrect parity start
  `3e+r_delta-1`, a vanishing claimed first nonzero parity, or residual
  scalars that remain independent after the weld vector is fixed.
