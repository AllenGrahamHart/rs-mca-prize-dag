# Result

Every surviving Mersenne row contains an explicit `n/2`-pair checkpoint
family obtained by embedding the exact order-`2(p+1)` antipodal construction
in its `m/2` subgroup cosets. It lives only at depths `p,p+1`. Its inner
polynomial is odd, so split values are nonzero sign pairs; on every `m=4`
row the maximal-degree exclusion forces exact value degree `h=2`. Hence
future work must classify and pay this family rather than seek total row
emptiness; the `m=4,h=3` exclusion branch is entirely nonembedded.
