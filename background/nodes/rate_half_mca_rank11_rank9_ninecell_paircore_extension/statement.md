# Rank-eleven rank-nine nine-cell pair-core extension

- **status:** PROVED
- **scope:** one lifted rank-nine affine owner plane fixed by nine coordinates

Let `B` be a nine-coordinate set on which the ten-dimensional correction
space has evaluation rank nine. Suppose `g` actual original-row records have
nonempty owner lines in the resulting affine owner plane. Let `J` be the
common pair core of the plane. Then `|J|>=9`, and exactly one of the
following bounds applies.

1. If `|J|<=134943`, then

   ```text
   g(g-1) <=981105*(2097152-9)=2057517483015,
   g<=1434405.
   ```

2. Otherwise the complete owner plane shares a pair core of size at least
   `134944`.

Thus the ten-cell theorem's integer plane cap is unchanged when the fixed
cell has only nine coordinates.

## Falsifier

A coordinate outside the common zero set agreeing with two owner points;
two size-`1116048` record supports through one owner whose intersection is
not in its pair core; a low-common-core nine-cell plane with at least
1434406 records; or a larger plane whose shared pair core is below 134944.
