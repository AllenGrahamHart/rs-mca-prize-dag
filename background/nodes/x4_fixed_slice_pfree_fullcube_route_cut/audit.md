# Audit

1. Full elementary prefixes determine power sums in every characteristic;
   only the inverse Newton map loses the `p`-multiple coordinates.
2. The syndrome reduction uses only `p`-free indices, so Frobenius-redundant
   equations are not counted as independent.
3. The fixed-slice fiber is bounded above by the full-cube fiber, but the
   latter has an unavoidable pigeonhole lower bound above `N^3`.
4. This refutes only the route that discards Hamming weight before taking a
   maximum. Weight-resolved collision moments, slice list recovery, and
   first-match owner decompositions remain viable.
5. No numerical experiment or random-model estimate enters the proof.
