# Audit

1. The proof guarantees only base order two from the correction contact. It
   does not add vanishing orders from distinct normalized branches.
2. The two missing orders are named as Hasse coefficients, so the statement
   is characteristic-safe.
3. The recurrence error begins in order six, leaving both order-two and
   order-three coefficient recurrences exact.
4. The equivalence with `D_1`-divisibility uses the exact determinant order
   four, not only a lower bound.
5. The Smith `[4]` conclusion is restricted to the branch where the full
   determinant divides the canonical image.
6. A shared root would have determinant order five and is not silently
   covered by this node.
