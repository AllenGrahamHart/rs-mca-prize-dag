# Result

At an unshared nonreduced correction root,

```text
F_i=z^2(x_*^i kappa_2+z x_*^i kappa_3+O(z^2)),
D_1|F_i for all i       iff kappa_2=kappa_3=0.
```

The local failure of the squarefree cubic quotient is therefore exactly a
two-scalar jet gate. Vanishing gives the cubic recurrence and Smith type
`[4]`.
