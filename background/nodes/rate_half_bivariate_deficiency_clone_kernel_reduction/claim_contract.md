# Claim contract

- **Claim:** every putative failing strict endpoint pencil produces the exact
  deficiency-aware kernel system `(DCK3)--(DCK7)`.
- **Dependencies:** endpoint saturation rigidity and the standard apolar
  moment identity for a joint representation.
- **Inputs:** the incidence sets `A_x`, joint-representation linear factors
  `L_x`, domain points, and deficits `Delta_x`.
- **Output:** an explicit matrix `M_W` with a blockwise-nonzero kernel vector
  and at most `|W|+m` columns.
- **Consumer:** the algebraic attack on `rate_half_band_crossing_location`.
- **Nonclaims:** no full-rank theorem, no generic-rank heuristic, no claim
  that row count implies rank, and no adjacent-crossing closure.
- **Falsifier:** a putative endpoint pencil for which a coordinate quotient
  has degree above `Delta_x`, the coefficient vector fails `(DCK5)`, or the
  unknown count differs from `(DCK6)`.
- **Replay:** `tools/ramguard tiny -- python3
  background/nodes/rate_half_bivariate_deficiency_clone_kernel_reduction/verify.py`
  and `verify_audit.py`.
