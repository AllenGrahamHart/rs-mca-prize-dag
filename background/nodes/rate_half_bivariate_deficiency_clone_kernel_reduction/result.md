# Result

The remaining algebraic route is now an exact finite-dimensional rank
problem. The old informal count of `|W|` scalar unknowns is correct only when
every point of `W` is saturated. In general each deficiency unit creates one
additional quotient coefficient, for at most `|W|+m` columns and exactly
`|W|` or `|W|+1` columns when `O=0`.

The next proof obligation is structural: establish enough rank for `M_W` on
the incidence patterns that violate the needed intersection cap. Comparing
the raw number of rows and columns is not a proof.
