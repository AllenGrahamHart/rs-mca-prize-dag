# Frontier

The full-V4 `(r,delta)=(2,4)` row is reduced to

```text
n=3,6.
```

For both degrees, the generic dihedral incidence gives a different unordered
pair of `Y` values at each `Z` value, so all four cross source-star edges can
be used without forced repetition. The next attack must use compatibility of
the cross-edge orientations around the three- or six-cycle, the source-cover
branch passport, or the actual coefficient equations. The other `m=2` types
are unchanged.
