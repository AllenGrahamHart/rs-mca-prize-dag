# Audit

The 7.4 MB primary packet is split into five digest-pinned JSONL shards.
The verifier checks every shard digest, byte count, record count, and JSON
record before streaming it. The unordered full run completed all 144 rows
without recovery or a remote exception.

Root ownership is independent: FLINT computes each field-root part by
Frobenius gcd. The direct audit independently reconstructs the three
`Pair(q,q)` branches, both reciprocal-square quadratics, their common
roots, all square lifts, and both final color lanes. It also joins every
paid free row to the exact tower-boundary or regularized-base certificate
that owns it.

The first direct-audit launch passed all arithmetic and failed only at the
final aggregate because an older field name was used. The corrected audit
passed all six chart jobs.
