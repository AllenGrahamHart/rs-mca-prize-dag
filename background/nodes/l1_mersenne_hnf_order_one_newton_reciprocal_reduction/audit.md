# Audit

This is an exact reformulation, not an approximation by low moments. The
`H-1` interior Newton equations plus the constant equation are equivalent to the full
reduced reciprocal identity. Using only the first three is explicitly a
necessary exclusion system, as in the successful order-zero eliminations.

Repeated `m`th-power roots cause no problem: Newton identities and elementary
symmetric functions are multiset identities.

The theorem removes `Res_W(L,Z-W^m)` from construction, but it does not
remove elimination in the parameter variables. A nonunit first-three system
is only a candidate locus and must not be promoted to an outer survivor.
