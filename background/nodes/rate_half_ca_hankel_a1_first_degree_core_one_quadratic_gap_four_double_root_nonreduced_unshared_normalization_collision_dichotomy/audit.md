# Audit

1. Unsharedness removes `R_*` over `tau`, so the correction multiplicities
   `2m_b` and `3m_b` in the two exact divisors are not contaminated by a
   supported branch.
2. The fixed domain-infinity factor relating `P_F|_C` and `s_F` is a unit at
   the finite heavy row; it changes neither valuation.
3. Fixed-row substitution changes `P_F` only by a multiple of `X-x_*`, of
   order `3m_b`. This is strictly above the contact order `2m_b`, so the
   equality in `(NCD3)` is exact rather than a lower bound.
4. Parameter ramification is retained through `e_b`; the argument does not
   assume the correction branches are etale.
5. The effective degree-two divisor has only the partitions `2` and `1+1`.
   Combining these with `s>=2` exhausts all integral solutions of
   `e_b s=2m_b`.
6. Specialized root multiplicity is the sum of parameter ramification
   indices over normalization branches at `(tau,x_*)`, not the coefficient
   sum of `B`. Both collision subcases give the exact sum two.
7. The theorem deliberately does not reuse the noncollision self-pairing
   classification after proving collision; its nonvanishing evaluation is
   false on the surviving branch.
