# Frontier

For one fixed prize row `(p,r)`, choose any retained profile-`(3,6,S=18)`
collision and write its normalized prime generator as `g`.  Every other
retained vector has the form

```text
alpha=pi^mu u g,       mu in {1,2,3,4},       u in R^x,
```

subject to the exact coefficient alphabet and profile constraints.  At
`mu=4`, only the primitive multiplicity-four support branch remains.

Inside one fixed `mu`, write `u` and `u^(-1)` in the power basis. Their
coefficients lie in the uniform boxes with radii `1006,503,251,125`. The
exact row radius `floor(18^64/(2^mu p))` is preferable when `p` is pinned.
The inverse equation

```text
U(X)V(X)=1 mod X^128+1
```

must be retained together with the two sparse product constraints
`U alpha=beta` and `V beta=alpha`; the raw box alone is far too large.

Modulo negacyclic shifts and sign, the alternative exact interface is the
rank-63 full-unit log lattice inside

```text
||lambda(u)||_1<=2(D_(mu,p)+sqrt(128D_(mu,p))),
D_(mu,p)=log(18^64/(2^mu p)).
```

The conductor-256 class-number theorem now proves that this is exactly the
integer lattice generated by the 63 standard real circular units
`eta_3,eta_5,...,eta_127`. A sharp entropy-height comparison now proves that
the `mu=2,3,4` bodies contain at most the torsion point relative to any chosen
anchor. Thus those three cofactors contribute at most one shift/sign orbit
each without lattice enumeration.

The exact target for this maximum-weight profile is now numerical:

```text
# {cofactor-2 full-unit log points satisfying the sparse profile}+3
    <=367.
```

Thus the residual necessary fallback is at most `364` cofactor-`2` points.
The count is over one representative modulo `mu_256`. This is only a profile
payment; lower-weight profiles remain.

The next theorem must work only in `mu=1`: count the integer circular-unit
exponent vectors whose products satisfy the sparse profile, or derive a
cofactor-`2` height/packing inequality that charges their full profile weight
in the weighted-kernel ledger.
Counting rational norm values independently is now strictly weaker because
every survivor already has the same normalized principal ideal.

because conductor 256 and the unconditional real class-number-one theorem
