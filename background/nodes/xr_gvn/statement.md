# XR generalized von Neumann reduction

- **status:** TARGET
- **status authority:** `dag.json`

Define `E_k(u,v)` to be a rigorously specified `k`-fold Johnson exchange
energy. Prove that unpaid alignment excess over the first-moment baseline
forces one of these energies to be quantitatively large, with constants and
an iteration endpoint sufficient for the downstream XR inverse theorem.

The exact fixed-slope pair moment in `averaged_xr` is evidence for the first
second-moment calculation, but it does not define the iterated energies or
prove the Cauchy--Schwarz endpoint. This node therefore remains a separate
target.

## Falsifier

An unpaid family with excess alignment but with every stated exchange energy
below the claimed threshold, or a proposed iteration whose accumulated loss
exceeds the downstream margin.
