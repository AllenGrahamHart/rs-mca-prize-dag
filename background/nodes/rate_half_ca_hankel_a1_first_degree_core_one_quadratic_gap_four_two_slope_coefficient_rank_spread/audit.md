# Audit

- The extra Vandermonde row comes from symmetry: the specialized left kernel
  has dimension `r_alpha+1`, unlike the core-free rectangular case.
- The fixed core is common to all actual error supports and disappears under
  contraction, so it contributes neither a difference point nor a zero
  source weight.
- Exact core degree one is part of the retained branch. After its fixed
  domain factor is contracted, a zero residual coefficient row would create
  a forbidden second fixed factor; no global point-separation theorem is
  used.
- The pair-union floor is `rho+2`; this is what changes the line inequality
  coefficient from one to two.
- The exact error deficits are one padded root in the double arm and zero,
  one, or two padded roots in the two-simple arm.
- The old cyclic abstract design is not claimed refuted; it has not yet been
  checked against the stronger spread.
