# Result

The first nonconstant X4/SP stratum has a precise local algebraic object:
translated divisor intersections between the fixed base locator and its
complement.  It is already coefficient-primitive, so quotient recursion does
not reduce it.  A same-linear-difference multiplicity witness rules out the
shortcut of counting only `aX+b`; the remaining proof must control the
divisor intersection with all first-owner predicates retained.
