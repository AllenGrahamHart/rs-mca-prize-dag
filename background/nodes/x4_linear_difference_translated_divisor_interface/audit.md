# Audit

1. `B` divides the fixed base locator and `B+H` divides the complementary
   locator; allowing both to divide the full domain locator loses the local
   first-owner information.
2. The count is over divisor incidences, not over low-degree polynomials
   `H`.  The explicit witness rejects injectivity in `H`.
3. Coefficient-primitivity at `d=1` follows from the necessary divisibility
   of an actual common scale.  It does not follow from the converse, which is
   false and is not asserted.
4. The witness is a route cut at `N=16`, not an official-row counterexample
   to the `16N^3` target.
5. Prior first-match strips still have to be imposed on the divisor incidence
   before an official residual count is claimed.
