# Linear-difference records are translated complementary divisors

- **status:** PROVED
- **closure:** proof

Let `D` be a finite evaluation set, fix an `m`-subset `S0`, and write

```text
L0=L_(S0),                 U=L_(D\S0).
```

For a second `m`-subset `S`, put

```text
C=S intersect S0,          P=S\S0,       Q=S0\S,
e=|P|=|Q|,                 A=L_P,         B=L_Q,
H=A-B.
```

Then depth-`t` prefix collisions with side width `e` are in bijection with
pairs `(B,H)` satisfying

```text
B is a monic degree-e divisor of L0,
A=B+H is a monic degree-e divisor of U,
H!=0,                      deg H<=e-t-1.              (TD-1)
```

The inverse takes the root sets `Q=Z(B)`, `P=Z(B+H)` and returns
`S=(S0\Q) union P`.  Thus the `d=1` part of a fixed local prefix fiber is
exactly a translated complementary-divisor incidence with

```text
H=aX+b,                    a!=0.                       (TD-2)
```

On a cyclic multiplicative coset every `d=1` record is coefficient-primitive:
any common quotient scale divides `deg(A-B)=1`.

The linear difference is not an injective key.  In `F_17^*`, generated by
`3`, fix

```text
S0={1,3,10,16,6}.
```

The three distinct supports

```text
{1,3,9,11,12},   {3,13,16,14,7},   {9,10,13,15,6}
```

have the same first locator coefficient as `S0`; after their respective
common cores are removed, all three satisfy

```text
L_P-L_Q=6X+10.                                      (TD-3)
```

Hence counting possible `H` does not count records, even for a fixed base
support and after coefficient-scale quotient removal.
