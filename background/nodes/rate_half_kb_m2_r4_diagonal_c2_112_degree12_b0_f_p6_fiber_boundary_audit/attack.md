# Attack

Do not extend the consecutive-fiber scan as a proof strategy. A global close
must allow `s` to range over all of `F_(p0^6)`, not only 63 printed base-field
values.

The next useful target is an elimination certificate showing globally that
every `F_(p0^6)` point of the reduced curve has

```text
V (s^2-4pvar) = 0,
```

or a component/residue-degree ledger proving the same statement. The
exceptional `s=2` dimension-one specialization must be handled separately.
