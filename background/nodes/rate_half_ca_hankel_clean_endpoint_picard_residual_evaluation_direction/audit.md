# Audit

1. The proof uses the fibre cohomology sequence, not a chosen monomial
   splitting of `pi_*O_C`.
2. Repeated occurrence of `S` is retained: `A_0` is then the local socle
   element `S^(e-1)` times a unit.
3. The residue cancellation is performed before evaluation, so it remains a
   simple residue even when the fibre root is repeated.
4. The modification direction is defined only up to a nonzero scalar, which
   is exactly the projective ambiguity in `(PED5)`.
5. `m>1` is essential. The known `m=1` fence is not promoted through this
   node.
6. The theorem selects the surviving splitting but does not claim a second
   section or clean-endpoint contradiction.
