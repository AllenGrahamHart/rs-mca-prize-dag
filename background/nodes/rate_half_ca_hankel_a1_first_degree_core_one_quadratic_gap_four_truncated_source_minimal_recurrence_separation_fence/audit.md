# Audit

1. The dimensions satisfy the exact core-one formulas at `e=5`.
2. Every original and compressed weight is nonzero.
3. Moment equality is checked for all powers `0,...,26`, exactly those used
   by the `14 x 14` Hankel matrix.
4. Matrix ranks are recomputed by finite-field elimination.
5. The kernel ideal and exact double-root multiplicity are checked directly.
6. The fixture is not presented as a global prize-packet counterexample.
