# Audit

1. Empty global common support makes every coordinate a nonloop.
2. Fundamental-circuit exchange supplies one new basis for each element
   outside a fixed basis.
3. Those bases are distinct because their outside elements are distinct.
4. The fixed-basis quotient argument depends on independence of `B`, not
   on a canonical tie-break.
5. Decoration is counted before division; no disjointness is assumed.
6. The integer incidence bound uses `floor(D_d/(d+2))`.
