# Upstream crosswalk

Checked against `przchojecki/rs-mca` `origin/main` at `b13de811`.

- `tex/cs25_cap_v13_2.tex`, `cor:circle-deployed`, defines the deployed
  Mersenne-31 line round as `D=chi(mathcal D)`, where `mathcal D` is a
  standard-position twin coset. It is not the multiplicative subgroup `H`
  used by this node.
- `experimental/proximity_prize_results_v4.tex`,
  `thm:saturation-pencil(iii)`, bounds primitive split-pencil charts by two
  finite bad slopes only after tangent, common-support, quotient, extension,
  degree-drop, and common-GCD branches are removed. That conditional routed
  slope count is different from this node's raw affine intersection cap.

The abstract torus theorem is therefore compatible with, but does not pay,
the deployed upstream M31 line round. A future import should present it as a
scoped multiplicative-subgroup lemma, not as a finite adjacent-row result.
