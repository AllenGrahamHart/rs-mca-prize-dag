# Audit

1. The rank lower bound uses only one cofactor block and remains valid if the
   second block creates further independent constraints.
2. Exact dimension is claimed only when `r=s`, where the target quotient has
   dimension `s`.
3. Projection to `F` is injective because `s<ell`; this is not inferred from
   a numerical rank sample.
4. Empty degree-`d` charts are separated before monic affine dimension is
   discussed.
5. The background set is uniquely reconstructed from `W_F`, but uniqueness
   does not make the number of realized sets polynomial.
6. No `binom(b,r)` union bound is accepted as a prize payment.
