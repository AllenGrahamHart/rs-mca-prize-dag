# Upstream crosswalk

For each fixed background root set, this node emits a split-locator flat with
codimension at least `ell-1`, so it is a concrete family for upstream's
master-flatness program. The complete fixed-`s` FPC5 problem is stronger than
independent flatness, however: it asks for a joint split-pair count in which
`F` splits on the source core and its linearly reconstructed numerator `W_F`
has at least `s` roots on the background.

This is closest to upstream's primitive shift-pair/second-moment language.
Any portable theorem must count the root-rich pair locus directly or compress
the realized background owners; applying a per-flat theorem and summing over
all root subsets loses the required polynomial bound.
