# Audit

The primary verifier pins the compiler, adapter, tower, kernel, independent
root packet, direct replay, and orbit router. The independent root program
uses Frobenius gcd rather than the compiler's root extraction. The direct
Modal replay reconstructs all relations and terminal ledgers from the
retained certificate.

The audit verifier symbolically checks `(P0-1)`, checks method markers in
both independent programs, and rejects a hostile census mutation.
