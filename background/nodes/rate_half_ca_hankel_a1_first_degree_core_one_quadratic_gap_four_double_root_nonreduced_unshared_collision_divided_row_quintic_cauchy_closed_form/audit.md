# Audit

1. The source set has `n_0=3p-2` points, while the largest polynomial in
   the barycentric sum has degree `3p-5`; there is no endpoint equality.
2. The sign in `(DCF4)` comes from using `y-x_*` in the divided row and
   `x_*-y` in the Cauchy moment.
3. The proof uses the complete source identity `(1)`, not inversion of the
   truncated `d+1` by `n_0` Vandermonde matrix.
4. All divisions by `L'(y)`, `x_*-y`, and `L(x_*)` are by nonzero
   base-field scalars because the source points are distinct and
   `x_* notin U_0`.
5. The formula explains the quintic cap; it does not claim that arbitrary
   quintic vectors arise from source data.
6. No factor-profile assertion is used, so this route fence applies to all
   retained unshared nonreduced collision profiles.
