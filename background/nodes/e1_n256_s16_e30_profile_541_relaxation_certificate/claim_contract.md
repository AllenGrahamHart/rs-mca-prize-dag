# Claim contract

## Input

`e1_n256_s16_e30_profile_parity_light_reduction`, including the complete
six-odd mask atlas and cutoff `M_3=1087`.

## Output

The exact exceptional magnitude-layer set consists of `1,456` assignments on
`321` affine light orbits.

## Falsifier

A missing mask, a second affine orbit for a mask, disagreement between the
independent scans, or a different exceptional count or maximum.

This node does not assert that an exceptional layer lifts to an actual sparse
vector and does not exclude profile `(5,4,1)`.
