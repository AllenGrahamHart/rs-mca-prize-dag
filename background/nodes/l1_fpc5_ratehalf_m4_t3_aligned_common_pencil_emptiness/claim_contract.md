# Claim contract

## Input

The exact complement-slice LS6 atom, optionally with an aligned
common-pencil presentation `(P-z_i, alpha z_i+beta)`.

## Output

- every nonempty atom has `deg Etilde>=a`;
- every aligned common-pencil atom has `Etilde` constant and is empty.

## Nonclaims

- common petal fibers alone force source-label alignment;
- a periodic locator makes the full agreement set periodic;
- misaligned common pencils or arbitrary locators are paid;
- the primitive master-flat census is bounded.
