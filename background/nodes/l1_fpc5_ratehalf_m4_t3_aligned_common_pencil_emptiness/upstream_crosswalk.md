# Upstream crosswalk

The theorem removes the most rigid split-pencil source before invoking
upstream `prob:capfr1-master-flatness`: a common degree-`ell` pencil whose
fiber values and source labels are affinely aligned contributes no LS6 point.

This is complementary to quotient/profile ownership. It proves emptiness
directly and therefore avoids the invalid inference that a periodic locator
automatically has a periodic full agreement set. Misaligned pencils remain a
split-in-subspace/master-flatness input.
