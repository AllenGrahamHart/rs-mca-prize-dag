# Audit

1. The product `D Etilde` has no leading cancellation because both factors
   are nonzero polynomials over a field.
2. The gate uses strict `deg Etilde<a`; equality is not excluded.
3. Alignment requires both `L_i=P-z_i` and affine source labels
   `c_i=alpha z_i+beta`.
4. Three common-pencil petal locators with arbitrary source labels need not
   satisfy the alignment hypothesis.
5. Emptiness is for the exact LS6 atom and requires no counting estimate.
