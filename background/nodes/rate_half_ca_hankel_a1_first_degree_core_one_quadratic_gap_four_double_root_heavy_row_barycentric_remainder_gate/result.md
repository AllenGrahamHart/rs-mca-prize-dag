# Result

The separated double-root augmented rank problem no longer requires a second
large coefficient-MDS matrix. Once the connected weld leaves its unique
candidate `lambda`, the complete heavy-row test is the coefficient vector of

```text
rem_H sum_x b_x lambda_x P_x(t).
```

The remaining theorem is now exact: prove this remainder nonzero for every
admissible source packet, or classify the packets on which it vanishes.
