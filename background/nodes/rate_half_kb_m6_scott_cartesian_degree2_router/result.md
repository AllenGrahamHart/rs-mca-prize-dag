# Result

PROVED. Every actual inner-degree-six transverse terminal is kernel-free,
in which case an exact degree-ten transitive-group classification forces
the excluded inner degree five, or has a nontrivial block kernel, in which
case Scott-compatible columns have size five or ten. Size five is excluded;
size ten has a same-fiber quartic suborbit and factors to inner degree two
or five. Thus every `m=6` producer dies or routes to `m=2`. The independent
frontier has 12 types in degrees `2,3,4`.
