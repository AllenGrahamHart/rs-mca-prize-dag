# Audit

1. `J` excludes the fixed core; its size is `rho-R-4`, not `rho-R-3`.
2. Residual slopes have deficit zero before their intersection with `J` is
   analyzed.
3. A slack slope supports no point of `X union Y` by definition of the full
   forward/reverse row-root union and lightness of those rows.
4. Every minimum-distance trigger uses actual supports. No padded heavy root
   is counted as an actual error coordinate.
5. At `g=e-1`, each missing `J` incidence on the `e`-slope center line needs
   exactly one outside incidence, not merely at least one.
6. Positive deficit in `W` is exactly one by `(6)`, so the number
   `e-6-d_L` in `(11)` is a count of slopes as well as deficit mass.
7. The contradiction uses only `e>=6`; the printed official value is far
   inside this range.
