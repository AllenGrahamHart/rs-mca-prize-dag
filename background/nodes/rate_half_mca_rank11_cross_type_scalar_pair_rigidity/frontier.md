# Frontier

The generic denominator allowance no longer obstructs a sharp cross-type
deck unless the scalar coefficient pairs are proportional. The next theorem
should therefore target the common-value-at-infinity branch:

1. prove that enough of the 520 quotient types admit connected 14+14 decks;
2. classify compatible cyclic/dihedral quotient maps with the same value at
   infinity; or
3. charge proportional-scalar classes by a chronology-safe owner.

Without one of these couplings, this node is a strict route reduction rather
than an aggregate payment.
