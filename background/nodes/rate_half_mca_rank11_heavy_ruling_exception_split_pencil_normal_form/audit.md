# Audit

1. The exception degree is positive by pair noncontainment and at most 11 by
   the low-pair core margin.
2. Exact support saturation makes every exception set have the same size
   `e`; it is not merely bounded by 11.
3. Exception sets are disjoint because two full agreement sets from one pair
   intersect exactly in the pair core.
4. The degree of `Qa_0'` is strictly below `m'`; the quotient degree bound
   after removing `L_0` is therefore exactly `e`.
5. A scalar-zero anchor would collapse every other exception locator onto
   one root set. Positivity of `e` is essential here.
6. Coprimality of `u,v` uses two split, pairwise-disjoint exception locators;
   no algebraic-closure root is ignored.
7. `gcd(Q,L_0)=1` is only denominator separation from the anchor core. It
   does not assert whole-domain root-freeness.
8. The upstream fixed rank-nine split-pencil census is not imported as a
   payment of this different bounded-exception pencil.
