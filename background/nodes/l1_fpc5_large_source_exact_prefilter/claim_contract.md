# Claim contract

- **Input:** one fixed maximal FPC5 source chart, touched set of `t` full
  petals, and defect degree `d`.
- **Output:** exact EMPTY, singleton, ordinary-Johnson, and joint-background
  filters `(PF1)--(PF7)`.
- **Preserved:** field, source layout, touched set, defect degree, exact
  contributor identity, and all primitive guards.
- **Forgotten:** nothing inside the fixed cell; only the subsequent aggregate
  sum is left outside this theorem.
- **Nonclaim:** a density over the full parameter grid or a polynomial bound
  for the residual satisfying `(PF6)`.
