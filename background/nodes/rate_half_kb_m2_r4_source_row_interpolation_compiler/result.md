# Result

PROVED. Twelve proposed source-row quartics come from a unique
bidegree-at-most-`(2,4)` biform exactly when a concrete `45 x 12` matrix
has a full-support kernel. Every actual interpolant also has complete-source
resultant proportional to `B^2`, or to `A(X^2)^2` in lifted diagonal
coordinates. Universal kernel failure is not proved.
