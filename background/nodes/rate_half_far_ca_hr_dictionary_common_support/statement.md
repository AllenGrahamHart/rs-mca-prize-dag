## Model (anchor-2 conventions)

`D subset F_q`, `|D| = n`, `v_x = 1/prod_{y in D, y != x}(x-y)`,

```text
y_m = sum_x e(x) v_x x^m,      M_r(y) = (y_{i+j})_{0<=i<rho, 0<=j<=r},
rho = R - r,                   R = n - k.
```

Both syndromes come from errors on a common set `T`, with `e_0 = 1` on `T`
and `e_1 = L` on `T`, `d = deg L`. Put `h_r = rank[M_r(y_0); M_r(y_1)]` and
`K_0 = ker` of that stacked matrix.

## (DICT) The dictionary — h_r is not a coordinate, it is a degree

```text
h_r = rho + deg(e_1/e_0)        and        dim K_0 = r + 1 - rho - d,
```

on the common support, **for polynomial ratio of degree `d <= rho`**,
**independent of the support size `s`**; `h_r = 2rho` when the ratio is not
polynomial **or has degree `d > rho`** — the stacked matrix has only `2rho`
rows, so the rank saturates.

## (CS) Common support is a THEOREM, not a family choice

> Any column-far pencil with two bad slopes is generated by two errors
> supported on `S_1 u S_2`.

Constructive: from two bad slopes `gamma_1 != gamma_2` with locators
`S_1, S_2`, solve for the weight-`<= r` errors `u_1, u_2` and set

```text
e_0 = (gamma_2 u_1 - gamma_1 u_2)/(gamma_2 - gamma_1),
e_1 = (u_1 - u_2)/(gamma_1 - gamma_2).
```

Then `syn(e_0) = y_0` and `syn(e_1) = y_1`, and `supp(e_0) u supp(e_1)` is
contained in `S_1 u S_2`. Verified exactly on `24` rows here (`12/12`, two
fields, in the source bank).
