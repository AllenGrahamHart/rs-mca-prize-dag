# Audit

1. A three-dimensional residual class equals the ambient residual base, so
   its root count becomes a common base for the whole bucket.
2. Zero evaluation columns are separated as `Z_0`; only nonzero columns are
   partitioned into projective clone classes.
3. A plane is the complete kernel of every nonzero evaluation functional at
   one of its roots. Distinct planes therefore use disjoint clone classes.
4. The plane count uses `U-q` available nonbase coordinates and `b-q`
   required coordinates. Replacing these by `U` and `b` separately would
   not be the same bound.
5. The maximum over `q<=10000` is checked exactly and occurs at the endpoint.
6. The mass pigeonhole uses the first-match residual-class partition.
7. Rank four is forced by the complete rank-three cap; the theorem does not
   claim that all algebraic products in `PB_i` are represented.
