# Proof

Every correction in the shortened rank-two bucket lies in `span(PH)`. If
`q>=10001`, all these corrections vanish on `Z_0`. The coordinates are
anchor-good, so every associated explanation equals the anchor and received
pair there. The proved same-record common-core adapter cancels the squarefree
locator of `Z_0`, transports every first-owned slope, and has a reversible
inverse lift. This proves output 1.

Assume now `q<=10000`. A three-dimensional residual class would equal `H`.
Its `37733` common zeros would then all lie in `Z_0`, contradicting
`q<=10000`. Hence every residual class `B_i` is a plane in `H`.

Fix such a plane. At least

```text
b-q>=37733-10000=27733                                  (1)
```

of its common-zero coordinates are outside `Z_0`. Evaluation on `H` at any
one of these coordinates is a nonzero functional whose kernel contains
`B_i`. Both spaces have dimension two, so the kernel equals `B_i`. Thus all
nonbase roots of `B_i` lie in the projective clone class of evaluation
columns with kernel `B_i`.

Distinct planes give distinct projective clone classes. These classes are
disjoint subsets of the `U-q` nonzero evaluation columns, and each uses at
least `b-q` coordinates. Therefore the number of planes is at most

```text
floor((U-q)/(b-q)).                                     (2)
```

The ratio `(U-q)/(b-q)` increases with `q` because `U>b`. Its maximum on
`0<=q<=10000` occurs at `q=10000`, where exact division gives

```text
floor(1106045/27733)=39.
```

This proves `(BP1)`. First-match residual classes partition the bucket, so
pigeonholing the mass `M` over at most 39 planes proves `(BP2)`.

The corrections of one plane class lie in `span(PB_i)`, of dimension at
most four. If their actual correction span had dimension at most three,
chronology-safe ownership would cap the class by

```text
R_3=3977322801<9965407986,
```

a contradiction. Its correction span therefore has dimension exactly four.
Equation `(1)` supplies the stated nonbase clone size. QED.
