# Audit

The value `g(1)` is computed only through degree six because the degree-seven
coefficient is zero on the inherited order-one curve. The equation is not
an evaluation of the infinite hypergeometric series.

Division by `r` is safe because `rho` and `c` are saturated nonzero. No
division by either quadratic leader is used in the resultant.

The degree-fourteen gcd endpoint is necessary only. The specialized
two-antipodal degree-eight endpoint remains preferable for that sub-chamber,
and a common root still owes the interpolant assignment and all outer and
inner tests.
