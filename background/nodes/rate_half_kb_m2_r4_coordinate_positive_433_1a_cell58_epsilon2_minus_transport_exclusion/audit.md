# Audit

1. The source signs are common square-root-lift signs, not the outside
   five-cycle sign.
2. The duplicate-role transport uses only `AB+1 <-> AB+2`; no `B <-> C`
   symmetry is asserted.
3. The sign transport flips `epsilon_1` and preserves `epsilon_2`; it does
   not claim that all four common sign rows are equivalent.
4. The parameter substitutions `r -> -r` and `t -> -t` preserve quotient
   labels and every source-label guard.
5. Outside source lifts are negated, so their product rows are fixed and
   their `q` values change sign.  The full sum-row identity uses the global
   coefficient involution `B_1 -> -B_1`; no outside placement is deleted.
6. The parent exclusion is uniform in deployed `t`, so using `t -> -t`
   loses no finite specialization.
7. The result closes four cell/sign rows, not cells `5,8` in full.
