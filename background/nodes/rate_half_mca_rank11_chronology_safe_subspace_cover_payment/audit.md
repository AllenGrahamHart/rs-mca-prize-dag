# Audit

1. The payment is summed over a partition, not an overlapping cover. An
   overlapping geometric cover must first assign each represented row space
   to one containing subspace.
2. The factor `n-A` is charged once per pair type inside each assigned class.
3. The ordinary-list cap is not squared: the inherited sub-square theorem is
   checked through `M_d^2<q` for every `d<=9`.
4. The residual allowance is `B_*-E_transverse`, not `B_*+1-E_transverse`.
   Equality with the allowance is safe; unsafety requires strict excess.
5. The two-block corollary concerns an actual cover of every represented
   row space. It does not refute the abstract two-block rich-atlas example.
