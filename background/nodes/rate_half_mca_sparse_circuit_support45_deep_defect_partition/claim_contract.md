# Claim contract

This node is a branch compiler.  It proves an exact partition of the two
completion maxima and the legality of reusing existing deletion,
cross-support, and joint-carrier caps on each child.

It does not assert that every exact pair is realizable.  Retaining
unrealizable pairs is harmless for an upper bound.  It does not itself close
any residual row, rank eight, rank eleven, or either prize problem.
