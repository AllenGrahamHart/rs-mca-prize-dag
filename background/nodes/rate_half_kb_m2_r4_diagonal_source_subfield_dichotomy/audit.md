# Audit

1. `sigma` preserves `K(W)` as a field but is not treated as a
   `K(W)`-linear automorphism.
2. Individual-star transport is used only when `sigma(K(X))=K(X)`.
3. In the other branch, two distinct quadratic intermediate fields fill
   the already-degree-four field; this is what proves the `V4` deck group.
4. The function-field `V4` is not the ambient `V4` component stabilizer
   deleted in the `(r,delta)=(2,4)` row.
5. The normal form is geometric and uses odd characteristic.
6. The fixed-point calculation uses tameness so distinct involution fixed
   sets are disjoint.
