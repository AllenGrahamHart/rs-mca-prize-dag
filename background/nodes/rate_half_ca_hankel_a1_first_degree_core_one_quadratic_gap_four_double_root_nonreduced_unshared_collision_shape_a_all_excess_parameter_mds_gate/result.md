# Result

All `3e` residual fiber polynomials now live in one exact homogeneous
system with only `4e` columns. The prior transposed gate used selected
zero-excess slopes and one scalar per selected fiber; this gate includes
every positive-excess and degree-drop fiber coefficient.

The smallest analogue is consistently full rank under two fields and one
hundred degree-preserving perturbations. This supports a direct rank route,
but the official theorem remains the absence of a block-supported kernel,
not generic full rank.

The follow-up partition scan covers all fifteen partitions of the `e=7`
excess and finds rank `28/28` in all `630` deterministic base/switched
realizations over two fields. This removes the initially tested spread
profile as a sampling bias, but it does not enumerate incidence tables or
establish an official-row theorem.
