# Audit

1. `F_29` is not the KoalaBear characteristic. The construction is a route
   cut, not an actual-row counterexample.
2. The edge data are genuine signed `J` edges, not coefficient-generated
   synthetic `(p,q)` values.
3. Defect is two, not zero: the repeated nonfixed edge orbit contributes two
   repeated edge labels. This remains within the parent defect budget three.
4. Rank seven is checked by both a kernel vector and a nonzero `7 x 7` minor;
   rank deficiency alone is not inferred from a sampled determinant.
5. Geometric irreducibility is checked separately. It does not supply the
   missing endpoint, coordinate-pole, or full-resultant realization.
6. The first quotient identity forces a unique quadratic. Testing arbitrary
   supported quadratics instead would hide the stronger support failure.
7. The full quotient failure is not promoted to a universal exclusion; it
   applies only to this exact packet.
