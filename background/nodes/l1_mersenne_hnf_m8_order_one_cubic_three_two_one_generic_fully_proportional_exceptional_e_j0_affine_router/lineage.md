# Lineage

This node consumes the final coefficient chart (FBC5), where the preceding
compiler retained `G_2` because both affine equations lost their `G_2`
coefficients. It does not rely on the generic `J_*!=0` reconstruction or on
the separate `a_2=0` and `S_1=S_0=0` routers.

The new identities expose a second affine reconstruction, this time for
`q`, and leave a bounded univariate common-root problem suitable for the
existing four-prime certificate packet.
