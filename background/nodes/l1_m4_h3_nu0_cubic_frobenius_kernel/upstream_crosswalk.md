# Upstream crosswalk - nu=0 cubic Frobenius kernel

This is a base-field split-pencil compression: the zero-valuation cubic
branch has a canonical three-scalar Frobenius kernel after the exact Cartier
ledger is paid. It gives a finite kernel interface for a split-pencil or SPI
classification without enumerating degree-`p` coefficients.

An upstream `(A)` packet can consume the two displayed identities as the
starting point of an exact exchange-degree ledger. They are not an exact SPI
count, an emptiness theorem, or an MCA row payment.
