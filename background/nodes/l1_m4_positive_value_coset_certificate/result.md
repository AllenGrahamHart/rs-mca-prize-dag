# Result

Positive valuation is impossible on the `p=8191` and `p=131071` official
`m=4` rows. On the `p=524287` and `p=2147483647` rows, every positive
valuation record has one projective depressed value triple and satisfies
`a^3+8b^2=0`. This is an exact finite certificate. The `nu=0` strata and the
two positive strata on the latter rows remain open, so L1 remains open.
