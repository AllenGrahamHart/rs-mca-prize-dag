# Audit

1. The theorem is an official-row arithmetic corollary, not a new geometric
   input.
2. Core-free degrees `m+1,m+2` are separated because the three-contact
   inequality alone does not cover both endpoints.
3. The transition at `e=rho/2` changes the interpolation degree from two to
   one.
4. The `s=1` lower bound uses `p<=Delta`; replacing `p` by `Delta` weakens
   the exclusion and is therefore safe.
5. Only `ell=0` is declared globally closed.
