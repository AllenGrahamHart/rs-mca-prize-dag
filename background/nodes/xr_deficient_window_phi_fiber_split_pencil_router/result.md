# Result

The affine-plane route now has an exact combinatorial endpoint.  Every
high-fiber selected block contributes the sharp number of distinct-`phi`
triples, while every block contributing none is a divisor of one or two
primitive pencil members.  Thus low fiber count is no longer an amorphous
`r<=2ell` range: the remaining obstruction is an explicit split-pencil
locator census.

The XR target remains open because that census and the high-fiber upper-tail
payment are not yet proved.
