# Claim contract

- **Claim:** the exact `e=7` all-excess row/fiber degree ledger admits a
  `K_all` kernel with every polynomial block nonzero.
- **Dependency:** the all-excess parameter-MDS equivalence.
- **Falsifier:** a wrong field order, set size, row/fiber root count,
  factorization, kernel equation, block-support assertion, or matrix rank.
- **Status effect:** route fence only; no critical node changes status.
- **Nonclaims:** no official incidence realization, source-pencil lift,
  spread certificate, collision packet, padding realization, or rate-half
  counterexample.
