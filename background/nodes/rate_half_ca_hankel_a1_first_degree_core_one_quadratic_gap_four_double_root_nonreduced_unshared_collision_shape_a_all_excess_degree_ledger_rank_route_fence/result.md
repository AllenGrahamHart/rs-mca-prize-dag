# Result

The broad candidate theorem “the exact all-excess degree ledger forces
`K_all` to have full column rank” is false. The smallest analogue has an
explicit rank-`27` matrix and a one-dimensional, fully block-supported
kernel arising from `t^5-X^7`.

The positive route is now narrower and better typed: an official exclusion
must use constraints absent from this example, especially the two-slope
spread, common source/Hankel pencil, collision jets, or positive-padding
normal form. Further random incidence scans cannot prove that theorem.
