# Audit

1. The second divided row is polynomial before specialization.
2. Reduction modulo the quadratic changes `P_(F,X)(x_*)` only in order
   three and higher.
3. The differentiated Pade syzygy uses the exact value `F_0=P_F(t,x_*)`,
   not the constant coefficient `b` of the remainder modulo `q`.
4. The recurrence uses `ord U_*>=3`; it does not divide by `X-x_*` after
   specialization without recording this order.
5. The derivative pairing `(PSD7)` is used only after `lambda_0=0`, when
   `W_tau` is actually in the specialized kernel.
6. Unsharedness removes center overlap before dividing by `Lambda(tau)`.
7. No vanishing of either split jet is inferred from local contact length.
