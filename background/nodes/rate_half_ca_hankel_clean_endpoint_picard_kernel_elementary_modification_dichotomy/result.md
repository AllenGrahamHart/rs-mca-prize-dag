# Result

The first proposed cohomological closure is refuted exactly. The multiplication
kernel is forced to have one of two elementary-modification splittings, so it
can never be section-free.

At this node the clean endpoint has two concrete branches:

1. a smooth rational locator curve with two degree-one sections;
2. a unique-section modification with splitting
   `O + O(1-rho) + O(-rho)^(m-2)`.

Both retain the four-Hankel frame and exact two-axis resultants. The proved
child `rate_half_ca_hankel_clean_endpoint_rational_elementary_branch_exclusion`
excludes the first branch, leaving only the unique-section modification.
