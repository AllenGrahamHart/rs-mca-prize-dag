# Audit

1. The kernel bundle is identified by exact direct images, not merely by
   matching rank and degree.
2. `P_*` is Cartier because `(TAP5)` identifies it with a line bundle; this
   justifies the length-one quotient in `(3)` even if the ambient biform curve
   has other singularities.
3. Local freeness excludes the zero extension class, which would leave a
   torsion direct summand.
4. Automorphisms of the equal negative block and evaluation-surjective maps
   `O(-rho)->O` give exactly two orbits, not a continuum of splitting types.
5. The negative-total-degree argument from the parent is explicitly
   retired: both allowed splittings contain a nonnegative summand.
6. Rationality is concluded only in the two-section branch. The
   unique-section branch remains live.
