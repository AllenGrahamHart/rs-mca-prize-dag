# Frontier

Run the same bounded common saturation on one sign representative of each
remaining orbit

```text
[0], [3,6], [4,7], [9,10], [11], [12,13], [14].
```

These seven calls are independent and cheap enough for one bounded Modal
map.  Any unit ideal deletes its entire orbit.  For a surviving common
finite algebra, append one necessary outside triple before authorizing a
larger outside ledger.
