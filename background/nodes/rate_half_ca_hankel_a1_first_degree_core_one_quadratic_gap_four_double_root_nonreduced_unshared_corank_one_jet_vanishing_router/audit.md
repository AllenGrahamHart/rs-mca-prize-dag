# Audit

1. The determinant order is four, not two or three; this is what raises the
   symmetric self-pairing through both missing jet orders.
2. Corank one is essential. For example `diag(z^2,z^2)` has determinant
   order four but its first basis vector has order-two self-pairing.
3. The proof first kills `kappa_2`; only then is the order-three coefficient
   exactly `kappa_3 U_tau(x_*)` without a derivative cross-term.
4. `U_tau(x_*)!=0` is the simple padded-root condition in the specialized
   `X`-fiber. It is retained explicitly rather than inferred from a double
   parameter root.
5. The conclusion uses the existing two-jet equivalence for divisibility
   and Smith type; those claims are not reproved with widened scope.
