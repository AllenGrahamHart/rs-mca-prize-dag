# Audit

1. The graph is formed from coefficient-image points, not normalization
   points; the branch multiplicities are retained as the weights `s_P,l_Q`.
2. `C_4`-freeness applies only after equal image points are grouped.
3. The domain root count is `n-a_delta-r_delta`: the padded root `x_*` is
   outside `U_0`, and the residual factor has no other `U_0` root.
4. A common parameter image gives proportional nonzero `X`-fibers, so
   `w_P` is well defined.
5. The genus charge uses distinct normalization branches and does not
   assume that the coefficient maps are injective at marked points.
6. The arithmetic-genus budgets are inequalities; unmarked singularities
   and singular individual branches can only reduce the available budget.
7. The theorem routes rank three but does not exclude it.
