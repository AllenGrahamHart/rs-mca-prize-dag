# Audit

The subgroup gate uses products counted with multiplicity. Repeated roots of
`R-z` are still domain elements because its radical is contained in `D`, and
the total product has exactly `p` factors, matching a complete split fiber.

The weighted-derivative gate excludes only the possible split value zero
before cancelling `beta_i`. In the zero-free chamber it is an identity
modulo all of `P`; in the other chamber the statement removes exactly that
one known linear factor.

The logarithmic-derivative argument is restricted to `z!=0` and to the two
printed invariants lying in `F_p`; only then can their residues be used as
integer exponents. It does not silently descend a non-prime-field passport.
The `ord_0(T)=1` route uses the complete split fiber `R=0` to force the
additional exponent `t` to vanish.

The `z=0` exclusion precedes that derivative argument. It uses the original
squarefree domain factorization: a complete split fiber and `D` cannot share
a root. No exponent or descent assumption enters this chamber.

The contradiction uses `m | p+1`, not only the displayed five numerical
rows. The verifier checks the exact residue and interval inequalities on all
five official instances.
