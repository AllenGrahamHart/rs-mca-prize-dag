# Claim contract

- **Proved:** at the official rate-half parameter scale, the residual
  side-width and changed-set intersection constraints admit more than
  `16N^3` abstract bipartite changed blocks.
- **Proved route cut:** no argument using only those combinatorial constraints
  can close the Johnson-nonpositive wedge.
- **Retained routes:** locator equations/divisibility, coefficient
  primitivity, and exact first-owner predicates.
- **Nonclaims:** the abstract family consists of shift pairs, lies in one
  locator-prefix fiber, survives any strip, or falsifies X4/SP/LIST/MCA.
