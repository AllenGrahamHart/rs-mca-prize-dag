# Audit

1. The paired construction respects the `P`/`Q` bipartition and exact sizes,
   not merely the changed-set size.
2. It is scoped to rate one half, where both sides contain the required
   `N/4` selected points.
3. The Gilbert argument is existential and exact; no random-code heuristic is
   used.
4. The blocks satisfy only the combinatorial consequence of the locator
   equations.  Treating them as actual shift pairs would be an overclaim.
5. The theorem retires an argument shape, not the Johnson-nonpositive wedge.
