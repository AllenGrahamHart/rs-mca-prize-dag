# Audit

The proof keeps four ranks distinct:

1. explanation affine rank `K`;
2. lifted and error affine rank `K+1`;
3. dimension `K+1` of the extension code `W`;
4. generalized-weight index `j`.

The generalized-weight proof uses the RS MDS hierarchy only on
`A intersect C`; it does not assume that `W` is MDS at rank one.  The
endpoint arithmetic is a ceiling of the existing corrected compiler, not a
new payment.  Two finite-field implementations check both a rank-one-defect
extension and an MDS extension, and the primary verifier recomputes the two
official endpoint bounds with exact integers.

Verdict: `NO ISSUE`.
