two nonprincipality tests. Published exact data predict the compact coordinate
set

```text
{ +/-29301^j mod 359057 : 0<=j<32 }.
```

longer need to be reconstructed. It suffices to prove that

```text
q_1 q_63 and q_1 q_65 are nonprincipal.
```

second the predicted 17-primary component. Any unconditional exact
