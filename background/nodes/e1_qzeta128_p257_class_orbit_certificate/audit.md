# Audit

- The exact field is `Q(zeta_128)`.
- Real class number one is derived from Miller's conductor-256 theorem by
  extension/norm and Weber oddness.
- The two proved products exclude involutions 63 and 65; odd class number
  excludes complex conjugation 127.
- Every nontrivial subgroup of the 64-element Galois 2-group contains an
  involution, so the stabilizer is trivial.
- Published class coordinates are corroborating evidence, not a dependency.
