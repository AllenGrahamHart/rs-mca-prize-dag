# Audit

The small-cell branch is a cardinality threshold, not a payment booked into
the old tangent/Q/BC sum. It becomes useful only inside the upstream maximum-
type completion theorem, whose exception set has size at most 31.

The adapter invokes classification separately on every 32-subset. Coherence
and exception routing across overlapping subsets remain exactly upstream
terminal `(E)`; they are not hidden in the word "adapter".
