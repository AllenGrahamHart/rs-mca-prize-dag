# Audit

This node is an exact polynomial remainder reduction, not an emptiness or
dimension claim. The equation `D_b=0` must remain in every branch: replacing
the two affine-linear equations by their determinant alone would admit
spurious points where both slopes vanish.

The exceptional split concerns only the coefficient of `b` in `M_5`.
Because `q-d` is saturated, it is exhaustive, but neither exceptional locus
is asserted inconsistent. On the generic branch, solving for `b` still owes
substitution in both `D_b` and `M_6`.

The reduction precedes the scale-free color ratio. Any retained p-free point
must still pass that ratio, exact fiber-degree and discriminant saturations,
the norm-color equation, assignment-preserving Frobenius, cyclotomic tests,
and the inner split-pencil lift.
