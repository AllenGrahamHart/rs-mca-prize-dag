# Frontier

The next useful theorem must consume information invisible to the local norm:

1. classify low-autocorrelation profile-`(4,4)` supports and their exact
   cyclotomic resultants;
2. prove a collective ideal-class/occupancy bound across different
   cofactors; or
3. replace the serial profile cap by a sharper mixed weighted payment.

A generic same-ideal height comparison is not enough: even an optimistic
one-orbit payment for each pure cofactor branch leaves fourteen branches,
while the current profile allowance is seven.
