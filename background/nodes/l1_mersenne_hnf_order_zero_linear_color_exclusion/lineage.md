# Lineage

The hypergeometric normal form reduces the order-zero endpoint to one
parameter `s`. The colored Frobenius lift records the pointwise values
`a^(p+1)`. This node exploits the first nonconstant degree stratum: a linear
color map is injective, so its image omits exactly one `m`th root of unity and
the resulting punctured-cyclotomic polynomial can be compared coefficient by
coefficient with `P_s`.
