# Audit

1. The statement covers every minimal tensor rank `r>=2`; it does not use
   planar image geometry.
2. Finite and infinite basepoints are excluded separately.
3. The exact total deficit permits one empty column, which is retained.
4. Fiber completion uses an incident row and its simple, completely split
   pullback divisor.
5. Divisibility is asserted for the active set, not all of `Gamma`.
6. Both possible active-set sizes are checked by exact gcds.
7. Birationality does not imply that the image is smooth or linearly normal.
