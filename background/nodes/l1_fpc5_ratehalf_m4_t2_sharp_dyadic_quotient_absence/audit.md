# Audit

1. The proof uses `n=2^41`, so every proper quotient scale is even.
2. `j=2ell-3` is odd independently of the value of `ell`.
3. The multiplicative action is free because the evaluation domain contains
   no zero.
4. Pure pullbacks and complete-orbit root sets are equivalent in this scope.
5. Partial-orbit tails and involutive fixed points defeat the parity argument
   and are not claimed absent.
