# Audit

- `C_tot` counts excess degree over supported parameter fibres. Thus a
  one-degree remainder outside the residual roots is subject to the ordinary
  cube divisibility and is impossible.
- The double-root row never uses the simple-root inequality. Its only upper
  bound before the local divisor calculation is the number of distinguished
  incidences `e-c_d`.
- The formally possible partition `(c_s,c_d)=(1,2)` in the ordinary packet
  is removed because it would require `t_d=e-1>e-2`.
- The point `P` is an overlap in three packets and an augmented new root in
  one; both local types have contact multiplicity two.
- The degree-one classes and section counts are classifications, not packet
  exclusions.
