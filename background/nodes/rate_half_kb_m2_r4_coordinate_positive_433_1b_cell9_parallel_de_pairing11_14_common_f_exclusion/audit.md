# Audit

The primary certificate is stored as six digest-pinned JSONL shards rather
than one large JSON document.  The verifier checks every shard digest, byte
count, record count, and JSON record before streaming it.

Root ownership is independent of the primary eliminator: FLINT computes the
field-root part of each profile by Frobenius gcd.  The second audit does not
trust primary root lists or terminal labels; it reconstructs source/kernel
values and every finite target cut directly.  It also joins each paid free
row to the exact tower-boundary or regularized-base certificate that owns it.

The failed 300-second monolithic replay and two wrapper bookkeeping failures
are not evidence.  The final six-chart replay passed all assertions and is
the only direct-audit run cited by the theorem.
