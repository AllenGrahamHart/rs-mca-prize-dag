# Audit

1. The resultant is taken in `X`; this node identifies the parameter
   projection, unlike the earlier `Res_t` affine quotient.
2. The formal-degree leading coefficient in `(2)` is retained until the
   exact exponent `2d+1` cancels it.
3. Center-line rank-loss factors cancel `Lambda^d`; they are not counted as
   residual intersections.
4. Positive-excess padding is included through the all-excess theorem.
5. Shared roots of `E_4` and supported forms add multiplicity rather than
   invalidating polynomial cancellation.
6. Homogeneous forms include parameter infinity.
