# Audit

1. Base-freeness is used only to make distinct projective pencil members'
   root sets disjoint. A common pencil zero is retained as an output horn.
2. The integer split is exact: `a(g)<T` means `a(g)<=T-1`, hence
   `b(B_i)>=H-T+1`.
3. A container is oriented once. A factor-heavy container is not also charged
   in the residual census.
4. Multiplication by nonzero `g_i` is injective in the polynomial ring, so
   `B_i` has the same dimension as `W_i`.
5. Fixed `g` uses direction space `gB` of dimension at most five. Fixed
   `B_i` uses `PB_i` of dimension at most `2 dim(B_i)`. No tensor map is
   assumed injective for these upper bounds.
6. Transversality is defined using labelled evaluation columns restricted to
   `B`; repeated or zero columns are therefore detected.
7. The adjacent threshold is a payment wall, not an unsafe witness.
8. The primary and independent verifiers use different binomial
   implementations and both scan every legal factor cutoff.
