# Audit

1. The original classified grid already has exactly `Rm_j` distinct
   factor incidences; the heavy row is disjoint from that row set.
2. Fiber capacity counts distinct roots, so `s_j` also counts distinct
   supported roots of one factor specialization.
3. Multiplicities or roots shared by factors can only increase
   `sum_j s_j`; the lower bound `e-6` remains valid.
4. No root of `S_BT_2` is assumed unsupported. The proof needs only that
   `g_*` supplies `e-6` supported roots.
5. Projective bihomogeneity prevents hidden degree drop at infinity.
6. The four-unit budget is global, but the safe factorwise consequence
   `u_j<=4` is all that is used in `(URB5)`.
7. Profile exclusions use the exact trichotomy and total parameter degree,
   not numerical experiments.
