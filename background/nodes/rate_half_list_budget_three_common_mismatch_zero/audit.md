# Audit

The proof uses selected-support coverage, not the stronger and generally
false assertion that every codeword selected every common agreement point.
Only one selected index is needed. At a common direction zero all four
values coincide, so that one selected agreement transfers to the common
value.

The conclusion concerns actual common zeros of the direction code, including
zeros not visible as degree-four selected incidences. Thus it proves `b=0`
without identifying `G` with the selected full-incidence block `F`.

Dropping `n_0=0` invalidates the theorem: an uncovered coordinate can carry a
common value different from `u`. The mutation audit checks this boundary.
