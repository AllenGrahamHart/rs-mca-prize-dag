# Audit

Exact divisibility in `(PC1)` uses `gcd(F,W)=1`; membership in the original
petal slice also uses the consequence `gcd(F,Lambda)=1`. The degree identity

```text
deg Lambda+e-1=2d
```

is the load-bearing bound on the reconstructed numerator.

The root-local guard is stated only for squarefree split locators disjoint
from the petals, exactly the FPC5 application. The common-root branch uses
the derivative of the determinant identity and the nonzero value `F'(x)`.
No numerical experiment or genericity assumption is used.
