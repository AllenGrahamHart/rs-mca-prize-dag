# Result

The 32-factor sign product now has an exact nested-quadratic representation:

```text
Psi_6 = Norm_(three quadratic pair products)(six-term Heron polynomial).
```

For each paired support, eight explicit `H_tau` factors partition the 32
signed lifts into blocks of four. This preserves the exact union of prime
supports while avoiding expansion of the degree-16 symmetric polynomial.

The next useful proposition is a deterministic pairing rule and a
prime-support bound for the resulting Heron factors. A norm census is not
authorized merely by this algebraic factorization.
