# Audit

The proof uses equality with the complete correction space, not merely
containment of the promoted containers in `PB`. The coordinate is retained in
`G_0`, so the anchor pair agrees with the received pair there. Both pair
components are checked; vanishing of only one component would not suffice.

The output is routed to `(C)`, not declared paid. No shortened-row bound or
chronology theorem is imported by this adapter.
