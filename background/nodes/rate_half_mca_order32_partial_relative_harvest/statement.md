# Partial relative order-32 explanation theorem

- **status:** PROVED
- **source:** upstream `experimental/grande_finale.tex`,
  `thm:partial-relative`
- **scope:** the deployed KoalaBear and Mersenne-31 MCA adjacent rows

Fix 32 distinct bad slopes. Maximalize their agreement supports and select
exact `m`-subsupports. Outside the global-affine, common-support,
pure-locator, denominator-root, and scalar-locator rational-profile cells,
every explanation satisfies

```text
18 <= degree_in_slope(E) <= 31,
chi(S) >= 3m-k+3.
```

The exact complexity floors are `2299571` on KoalaBear and `2299499` on
Mersenne-31. If every residual 32-subset is affine or rational, then all bad
slopes lie in one coherent structure or a 31-overlap belongs to the
quantified near-sunflower branch.

This is a classification theorem. It does not prove `(S)`, `(A)`, `(E)`, or
an adjacent safe row.
