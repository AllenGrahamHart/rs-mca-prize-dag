# Audit

## Source

Upstream `#1159` records the pole-line `d1=67473` sensitivity theorem and
retains `(1_E,X^k)` as a mutation/regression control.  This packet proves the
control's exact semantic content directly and pins the upstream note and two
primary verifier blobs.

## Witness semantics

The same received pair, slope, and support are used under both dimensions.
Only the code space changes.  The proof checks individual explainability and
pair noncontainment on that identical support; it does not infer either from
a numerical profile label.

## Scope

The counterexample kills an unguarded dimension substitution, not every
possible adapter.  A repaired adapter may retain `K=k` or explicitly reject
coefficient degree `k` before assigning an owner.

## Independence

The primary verifier reconstructs the Pocklington, subgroup, interval, and
degree ledgers from the source contract and rejects eight mutations.  The
independent audit retypes the deployed constants and checks the two code
membership decisions without importing the primary verifier.
