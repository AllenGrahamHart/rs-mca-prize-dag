# Upstream crosswalk

This is exact finite-row shift-pair control for the `h=7` cubic packet in
draft PR #1120. In upstream terminology it converts retained coefficient
factors into an exact primitive shift-pair outer replay: normalized role
colors, pointwise Frobenius, and cyclotomic divisibility are checked in one
generated field with constants printed.

It is suitable for the same PR because it consumes that packet's role
compiler and coefficient-field router. It must be presented as a compiler,
not as a computed exclusion or an inner-lift theorem.
