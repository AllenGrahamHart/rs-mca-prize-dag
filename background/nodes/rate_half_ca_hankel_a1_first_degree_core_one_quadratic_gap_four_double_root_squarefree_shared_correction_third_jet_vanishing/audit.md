# Audit

1. The regular corank is exactly one because the full specialized Hankel
   kernel is `U_tau F[X]_(<=1)` and one line is the permanent primitive
   kernel `Q_tau`.
2. The Schur-complement lemma uses symmetry essentially; determinant order
   alone would not force the quadratic self-pairing to order three.
3. The vector lift may have order-two regular components. The lemma allows
   them and shows their self-pairing begins only in order four.
4. The leading direction in the shared gate is the evaluation vector
   `nu(x_*)`, whose pairing with `u_tau` is exactly `U_tau(x_*)`.
5. Simplicity in the `X`-fiber, not squarefreeness only in parameter, gives
   `U_tau(x_*)!=0`.
6. The conclusion settles the squarefree shared jet but makes no assertion
   at a double parameter root of `S_B`.
