# Frontier

Do not recompute the generic chart-2 `DE+/DE-/BE` gcd.  The remaining
cell-5 work is now:

1. repeat the same `DE+/DE-/BE` component calculation on rational `c` charts
   3--5, preserving each selected chart denominator;
2. compute the finite exceptional-`t` locus from the primitive, coordinate,
   atlas, and guard denominators and treat those deployed-field fibers;
3. combine the four chart ledgers before claiming a generic sign-row or cell
   deletion.

There is no declared `B <-> C` symmetry: their common multiplicities differ.
The `DF+/DF-/CF` analogue is therefore a separate possible route, but it is
not needed if the `DE+/DE-/BE` family is excluded on all four rational
charts.
