# Audit - L1 m=4, h=3, nu=2 base-field normalization

1. The theorem applies only to the two characteristics that survive the
   positive value-coset certificate.
2. The Belyi tangent value `y_0'=-S_e(0)` is nonzero because all tangent
   roots are nonzero.
3. The projective value scale satisfies `y_0=3s/4`; hence
   `s/lambda^p` is in `F_p`.
4. The normalized cubic is `Y^3-2c^2Y+c^3`, with no hidden coefficient
   extension.
5. Both characteristics are `2 mod 5`, so the quadratic pair is genuinely
   conjugate rather than separately fixed.
6. A prime-field polynomial has a Frobenius-stable full root set.
7. The root set lies in both `C` and `C^p`; nonempty intersection of subgroup
   cosets proves equality.
8. Equality of the cosets forces `A^p=A`, not necessarily `A=1`.
9. Exact quotient of two prime-field polynomials is prime-field because the
   divisor is monic.
10. Base-field normalization is a structural reduction, not an exclusion.
