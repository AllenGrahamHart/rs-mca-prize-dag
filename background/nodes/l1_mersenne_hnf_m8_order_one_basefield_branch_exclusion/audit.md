# Audit

The proof uses both sides of the split-root condition. Equation (BBE1) is
what makes `1-x` a root of the Frobenius polynomial; the inherited
cyclotomic divisibility then makes it an `n`th root. A bare coefficient
reflection without that divisibility is insufficient.

The six-point bound is an upper bound, not an existence classification. It
does not require the three final quadratics to split or have disjoint root
sets. This makes the contradiction robust.

The result is scoped to the base-field conic parameter. No inference is made
for `t notin F_p`, `h=15`, lower value degree, `m=4,h=2`, or any inner lift.
