# Attack

The exact wall at `K'=18159` has the same hierarchy spanning tree as the
endpoint.  Progress must strengthen at least one of:

- the corank-one individual cap;
- the full-containment resource;
- a binding tree edge;
- a cycle-consistency row beyond what the current tree dual prices;
- a new resource independent of the multi-step hierarchy.

The higher-step rows `t>=4` do not improve the present LP beyond the `t=2,3`
rows.  Replaying more redundant shadow sizes is therefore not a useful next
attack by itself.
