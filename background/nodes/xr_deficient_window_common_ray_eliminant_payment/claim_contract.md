# Claim contract

| field | value |
|---|---|
| claim | The common-ray matrix-pencil cap `(CRE1)--(CRE4)`. |
| inputs | Active-defect nonvanishing, pairwise distinct `phi` values, core-cut incidence, and the same-ray interaction strip. |
| output | At most `m+1` target owners per fixed tuple, plus the exact improved `ell=1` cutoffs. |
| load-bearing hypotheses | Affine slice dimension `m`, linear parameter dependence, distinct pole directions `[W_i]`, and first-match same-ray ownership. |
| falsifier | `m+2` target owners for one fixed tuple, generic consistency of the ray pencil, or failure of an exact cutoff comparison. |
| nonclaim | No assertion that the first cap failure is unsafe and no split-pencil census. |
