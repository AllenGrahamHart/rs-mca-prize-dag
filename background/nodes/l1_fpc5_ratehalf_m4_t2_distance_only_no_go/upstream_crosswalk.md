# Upstream crosswalk

This is a quantified no-go fence for the primitive shift-pair lane. The exact
FPC5 determinant supplies a valid distance layer, but even its sharp block
parameters admit abstract constant-weight codes of size
`2^(0.099865... ell+o(ell))`.

Accordingly, upstream exchange/second-moment work must use the algebraic
cofactor flat, moment-curve incidence, or received-word ownership. A theorem
whose only hypotheses are support weights and pairwise overlaps cannot close
this consumer.
