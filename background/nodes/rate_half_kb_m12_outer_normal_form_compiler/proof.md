# Proof

All coordinates in this proof are geometric. Affine source and target
changes preserve the unique total pole at infinity.

## 1. The dihedral type

For `r=2`, the primitive degree-five subdegree row is `(1,2,2)`, so the
geometric monodromy is `D5`. Its infinity cycle is a rotation of order five.
The finite ramification index sum is four. Every nonrotation in the degree-
five dihedral action is a reflection of cycle type `(2,2)`, index two. A
finite rotation would consume all four units and generate only the cyclic
group with the infinity cycle. Therefore a dihedral cover has exactly two
finite reflection branch cycles.

The Galois closure `X` has group order ten and branch orders `5,2,2`.
Riemann-Hurwitz gives

```text
2g(X)-2=10(-2+(1-1/5)+(1-1/2)+(1-1/2))=-2,
```

so `X=P^1_z`. Conjugate the dihedral action to

```text
z -> zeta*z,             z -> a/z,
```

with `zeta^5=1` and `a!=0`. The reflection fixed field is generated by
`x=z+a/z`, while the full dihedral invariant is `z^5+(a/z)^5`. The identity

```text
z^5+(a/z)^5 = x^5-5a*x^3+5a^2*x
```

gives the Dickson form. The two point-stabilizer orbits `{+/-1}` and
`{+/-2}` give the two quadratic factors in `(KBN-1)`; direct multiplication
verifies the displayed coefficients.

## 2. The five r=4 profiles

Write `P` for an affine-normalized polynomial. A ramification point of index
`e` occurs with multiplicity `e-1` in `P'`.

### A5 profile `(3),(2,2)`

Send the index-three point to zero and the two index-two points over the
other branch value to `1,t`. Then

```text
P'(x) = c*x^2(x-1)(x-t).
```

Equality `P(1)=P(t)` is equivalent, for `t!=1`, to

```text
3t^2+4t+3=0.
```

Integration and target scaling give

```text
P=x^3(12x^2-15(1+t)x+20t).
```

### A5 profile `(3),(3)`

Send the two index-three points to zero and one. Then

```text
P'=30x^2(x-1)^2,
P=x^3(6x^2-15x+10)
```

after target scaling and translation.

### S5 profile `(2),(3,2)`

Send the index-three and index-two points in the common branch fiber to
zero and one. If `c` is the remaining simple critical point, then

```text
P'=k*x^2(x-1)(x-c).
```

The equality `P(0)=P(1)` gives `c=3/5`. Integration gives
`P=x^3(x-1)^2` up to target scaling.

### S5 profile `(2),(4)`

Send the index-four and index-two critical points to zero and one. Then
`P'=k*x^3(x-1)`, and integration gives `P=x^4(5-4x)` up to target affine
change.

### S5 profile `(2),(2),(2,2)`

Send the two simple critical points in the repeated branch fiber to zero
and one, and call the other critical points `u,v`. Then

```text
P'=k*x(x-1)(x-u)(x-v).
```

The equality `P(0)=P(1)` is

```text
5(u+v)-10uv-3=0.
```

Put `t=uv`, so `u+v=2t+3/5`. Integration gives

```text
P=x^2(x-1)^2(2x-5t)
```

up to target scaling. The original branch profile supplies the open
conditions that the four critical points are distinct and the other two
critical values are distinct from each other and from the repeated value.

These cases exhaust the five proved low-genus profiles, while Section 1
handles the separate dihedral survivor. QED.
