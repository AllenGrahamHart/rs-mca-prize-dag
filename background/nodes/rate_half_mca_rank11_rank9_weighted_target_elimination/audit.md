# Audit

The low-dimension argument uses strict core size `<m'`, which comes from
same-support pair noncontainment and is not a root-bound surrogate. The
large-dimension comparison keeps both sides in `(record,T)` units.

Uniformity is analytic: after cancellation, every nonconstant factor in
`L/U` is an increasing ratio with the same additive shortening parameter.
No million-row scan is part of the proof.

The primary verifier rejects eight mutations. The independent verifier
checks the low/high partition, the exact boundary cross-product, and
monotonicity on hostile adjacent dimensions.
