# Audit

1. The product norm is over all `3e` supported off-line slopes, not only
   zero-excess or clean fibers.
2. No specialization is identically zero; this is inherited from the
   primitive factor-saturation theorem.
3. Actual-support roots are vertically simple by the all-excess
   factorization, so the classified-row order is exactly `m`, not merely at
   least `m`.
4. Exact row order proves `gcd(S_Q,L_0)=1`; no squarefreeness of `S_Q` is
   asserted.
5. The `x_*` statement is divisibility only. Two-dimensional transversality
   at a padding point does not force vertical simplicity of the specialized
   factor.
6. `tau` is not in `Gamma`, so the correction order does not enter the
   norm product.
7. The residual `E_Q` may still vanish at `x_*`; no exact order is claimed.
8. The degree cap permits specialization degree drops and roots at projective
   infinity; it is therefore an upper bound, not an equality.
9. The interpolation formula uses only values on `U_0`; computation is not
   load-bearing.
