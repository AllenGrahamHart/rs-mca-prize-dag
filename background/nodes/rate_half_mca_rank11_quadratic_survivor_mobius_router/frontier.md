# Frontier

For the quadratic branch, the only local nonquotient target is now the exact
shifted-inversion intersection

```text
I(tau,kappa)=#{x in H:
  x!=-tau,
  kappa/(x+tau)-tau in H,
  kappa/(x+tau)-tau!=x},
```

with `tau,kappa!=0`. A synchronized survivor forces `I>=8740`. The affine
census does not control this two-parameter family, and the published
`32N^(2/3)` curve bound is too weak. Any proposed cap should first be tested
against exact sampled parameters and the constant-product limit `tau=0`.

A preregistered 6144-parameter Modal probe found maximum `I=2336`, with
99th percentile `2218`; the `8740` threshold survived by 6404 points. This
supports, but does not prove, a sharp official shifted-inversion cap.

The antipodal and constant-product classes are global quotient classes and
must be priced using retained factor-owner or chronology semantics. Degrees
`1,3,...,11` still require their own pullback/primitive split.
