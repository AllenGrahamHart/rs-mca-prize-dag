# Audit

1. Edge labels are defined only on nonincidences, where both polynomial
   values are nonzero.
2. The cycle product is oriented consistently; reversing a cycle inverts
   both sides and does not change the condition.
3. Four-cycles establish pair-transition independence, not triangle
   consistency by themselves.
4. Extremal transition triangles are automatic only because every three
   fiber neighborhoods share at least `6+d_A` rows.
5. The strict profile retains transition triangles explicitly; pairwise
   overlap alone is not silently upgraded to triple overlap.
6. Passing the cycle certificate reconstructs only the unique weld scalar.
   It does not imply `Krow lambda=0`.
