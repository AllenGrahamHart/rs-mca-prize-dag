# Audit

The 9.1 MB primary packet is split into five digest-pinned JSONL shards.
The verifier checks every shard digest, byte count, record count, and JSON
record before streaming it. The unordered full run completed all 144 rows
without recovery or a remote exception.

Root ownership is independent: FLINT computes each field-root part by
Frobenius gcd. The direct audit independently reconstructs the three
`Pair(q,q)` branches, the quartic missing cut, and the quadratic next-pair
cut. It proves directly that their common-root set is empty before any
`z/d/e/f` lift or final color lane. It
also joins every paid free row to the exact tower-boundary or
regularized-base certificate that owns it.
