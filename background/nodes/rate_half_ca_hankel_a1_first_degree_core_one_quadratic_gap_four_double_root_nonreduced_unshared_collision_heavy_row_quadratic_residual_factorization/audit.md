# Audit

1. Only simple divisibility by `g_*` is used; no unsupported multiplicity
   at padded fibers is assumed.
2. Bihomogeneity and nonzeroness make `G(t,x_*)` a binary form of exact
   projective degree `e-2`; affine degree drop is a root at infinity.
3. The degree-four quotient comes from this exact row degree minus
   `deg g_*=e-6`, not from the determinant quartic.
4. Exact order two at `tau` is already proved by the Pade value-row gate.
5. Unsharedness is used before dividing by `g_*(tau)`.
6. `S_B` is a degree-two square with the sole divisor `2[tau]`, so the
   residual quotient is nonzero at `tau`.
7. The quotient has exact projective degree two; it is not asserted to
   split over the base field.
8. The remainder matrix is a gate, not a rank conclusion.
