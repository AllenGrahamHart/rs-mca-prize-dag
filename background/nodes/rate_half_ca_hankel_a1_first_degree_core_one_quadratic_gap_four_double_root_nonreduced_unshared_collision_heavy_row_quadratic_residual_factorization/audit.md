# Audit

1. Only simple divisibility by `g_*` is used; no unsupported multiplicity
   at padded fibers is assumed.
2. The degree-four quotient comes from `deg G(t,x_*)<=e-2` minus
   `deg g_*=e-6`, not from the determinant quartic.
3. Exact order two at `tau` is already proved by the Pade value-row gate.
4. Unsharedness is used before dividing by `g_*(tau)`.
5. `S_B` is a degree-two square with the sole divisor `2[tau]`, so the
   residual quotient is nonzero at `tau`.
6. The quotient degree is at most two; it is not asserted to be exactly
   two or split.
7. The remainder matrix is a gate, not a rank conclusion.
