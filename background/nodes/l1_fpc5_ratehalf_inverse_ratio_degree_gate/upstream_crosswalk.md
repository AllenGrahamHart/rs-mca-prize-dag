# Upstream crosswalk

The gate converts an LS6 exactness condition into a source-only exclusion:
the modular ratio `L_1/L_2 mod L_3` cannot have degree below the defect `a`.
The failure branch is exactly a two-coefficient short syzygy

```text
L_1=U L_2+R L_3,       deg U,deg R<a.
```

This is a concrete strip/split-pencil census input. Common pencils are the
degree-zero stratum, while higher short syzygies supply the next natural
classification rungs. No maximum-fiber payment follows without that census.
