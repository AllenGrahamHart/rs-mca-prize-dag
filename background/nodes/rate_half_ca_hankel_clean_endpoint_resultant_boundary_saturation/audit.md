# Audit

1. `H` is made monic only by a nonzero scalar normalization; no root or
   multiplicity changes.
2. The actual degree `b=deg_z B` is retained. The proof does not replace it
   by the upper bound `m-1`.
3. The argument at a root of `q_inf` checks both the projective parameter
   point at infinity and every finite parameter root before declaring the
   resultant nonzero.
4. `q_inf` has no domain root because parameter infinity was chosen outside
   all roots of every domain-row specialization, not merely outside `Z`.
5. The degree bound for a resultant is used in the correct direction. Its
   equality forces `deg_X B=N`; it does not assume generic leading terms.
6. The theorem refutes the tempting boundary-free norm shortcut. It does not
   refute the clean endpoint itself.
