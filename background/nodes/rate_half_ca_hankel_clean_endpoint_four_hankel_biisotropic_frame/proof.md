# Proof

The regular rank-drop divisor, the discriminant of `Q` in `X`, and the
constant and leading `X`-coefficient forms have only finitely many parameter
zeros. The clean norm theorem also leaves only the finite supported and
residual root set. Choose two projective parameter points outside their
union and send them to `0` and infinity. This is compatible with the
normalization in the boundary-saturation theorem.

The rational-normal kernel theorem proves that the coefficient vectors
`q_0,...,q_m` are linearly independent. This gives `(FHB2)`.

The full rectangular Hankel pencil has rows indexed `0,...,rho+1` and
columns indexed `0,...,rho`. Its top and bottom square blocks are exactly

```text
H_0(z)=H_(0,0)+zH_(0,1),
H_1(z)=H_(1,0)+zH_(1,1).                            (1)
```

At either chosen endpoint the rectangular matrix has rank `rho`, right
kernel generated by the endpoint vector `q`, and left kernel generated by
the two shifted coefficient vectors

```text
E_0q=(q_0,...,q_rho,0)^T,
E_1q=(0,q_0,...,q_rho)^T.                           (2)
```

For the top square block, a second row dependence would be a combination of
the vectors in `(2)` whose final coordinate vanishes. The nonzero top
coefficient `q_rho` makes that combination a multiple of `E_0q`; hence the
top block has rank `rho` and kernel `span{q}`. The same argument at the first
coordinate proves the bottom claim using `q_0!=0`. Applying this at `0` and
infinity proves `(FHB4)`.

Fix `epsilon`. Expanding `H_epsilon(z)q(z)=0` gives

```text
H_(epsilon,0)q_0=0,
H_(epsilon,0)q_j+H_(epsilon,1)q_(j-1)=0  (1<=j<=m),
H_(epsilon,1)q_m=0.                                 (3)
```

Put `C_(i,j)=q_i^T H_(epsilon,1)q_j`. Symmetry and `(3)` give, for
`i<m` and `j>0`,

```text
C_(i,j)=C_(i+1,j-1).                                (4)
```

If `i+j<=m`, iterate `(4)` to `C_(i+j,0)`, which vanishes by pairing the
next equation in `(3)` with `q_0`, or by the terminal equation when
`i+j=m`. If `i+j>m`, iterate to `C_(m,i+j-m)=0`. Thus every `C_(i,j)`
vanishes. Equation `(3)` then gives the same assertion for
`H_(epsilon,0)`. Since `epsilon` was arbitrary, `(FHB5)` follows.

The chosen affine expansion identifies its highest parameter coefficient as
`Q_m=q_inf`, proving `(FHB6)`. Finally expand the two Hankel pairings using
the source moments:

```text
q_i^T H_(0,s)q_j
 =sum_x omega_x^(s)Q_i(x)Q_j(x),
q_i^T H_(1,s)q_j
 =sum_x x omega_x^(s)Q_i(x)Q_j(x).
```

Collecting these scalar identities gives `(FHB7)`. The description of each
`v_x` is the clean row factorization already proved by norm saturation. QED.
