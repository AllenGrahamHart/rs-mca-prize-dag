# Audit

1. The endpoint coordinate is chosen outside every printed finite exceptional
   set. The proof does not assume that a supported slope is generic.
2. The top and bottom square-block rank argument uses the full two-dimensional
   left kernel and both nonzero endpoint coefficients; rectangular rank alone
   would not suffice.
3. The four isotropy identities are proved separately for the two adjacent
   Hankel blocks. One middle matrix is not silently substituted for the full
   rectangular pencil.
4. `q_inf` is the highest parameter coefficient polynomial `Q_m`, not the
   leading `X`-coefficient of `Q`; the two are kept distinct.
5. The source weights in `(FHB7)` include the dual RS column multipliers from
   the split-pencil normalization.
6. The `m=1` audit is a chain-level control only. The theorem's clean
   irreducible scope remains `m>1`.
