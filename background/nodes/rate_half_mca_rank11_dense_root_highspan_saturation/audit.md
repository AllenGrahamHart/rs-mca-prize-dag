# Audit

1. The eighteen roots come from actual dense-pair anchor records in the
   fixed tuple; they are not inferred from pair multiplicity elsewhere.
2. The ten deviation-basis records are also in that tuple, so their values
   force the coefficient span to be all of `V'`.
3. Divisibility by the dense-root locator is coefficientwise over the code
   vector space and uses distinct slopes.
4. Monicity makes degrees `18..31` a triangular, invertible image of all
   quotient coefficients; no division by a locator coefficient is hidden.
5. Subtracting the pair line changes only slope degrees zero and one.
6. Equality `W=V'` uses both directions: correction containment and high
   absorption.
7. A common ambient correction space is not a component count. No aggregate
   payment is claimed.

No numerical experiment or Modal computation is used.
