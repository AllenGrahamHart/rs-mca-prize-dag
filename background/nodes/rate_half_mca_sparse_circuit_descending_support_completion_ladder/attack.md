# Attack record

The single-source support-five split leaves an expensive all-at-most-`q-5`
branch.  That branch still contains unused information: support-four,
support-three, and support-two deletion maxima also obey the universal
completion ceiling.  Reapplying the same exact split recursively converts
the broad fallback into a finite descending ladder.

The ladder is deliberately independent of any numerical row.  Its value is
that later payments can price every support stratum jointly without hiding
a speculative premise.
