# Proof

Identify the evaluation subgroup with `Z/nZ` through an element `zeta` of
order `n`. A subset is nonprimitive exactly when its rotation stabilizer is
nontrivial. Every nontrivial subgroup of the cyclic `2`-group `Z/nZ`
contains its unique element of order two, namely `n/2`. Hence

```text
B is nonprimitive  <=>  B+n/2=B.                         (1)
```

Such a set is a disjoint union of antipodal pairs
`{zeta^i,-zeta^i}` and therefore has even size. It is uniquely represented
by a subset `A` of the order-`n/2` subgroup generated by `zeta^2`.

For an odd power `r`, each pair contributes zero. For `r=2u`, it contributes

```text
(zeta^i)^(2u) + (-zeta^i)^(2u) = 2 (zeta^2)^(iu).
```

Because `q` is odd, multiplication by `2` is invertible. Thus the first `t`
power sums of `B` vanish if and only if the first `floor(t/2)` power sums of
`A` vanish. The pairing is a weight-preserving bijection after division by
two, so (1) gives the two fixed-weight formulas.

Summing over any interval gives the first-owner count formula directly. If

```text
X(n,t) = q^t 2^(-n) sum_b T(n,t,b),
```

then for even `t` the normalized contribution of all nonprimitive sets is

```text
q^t 2^(-n) sum_c T(n/2,t/2,c)
 = (q^(t/2)/2^(n/2)) X(n/2,t/2).
```

Subtracting it proves the displayed normalized identity. The same argument
with restricted sums gives the central half-band version used by the prize
consumer.
