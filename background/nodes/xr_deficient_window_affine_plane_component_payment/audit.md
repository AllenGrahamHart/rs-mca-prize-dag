# Audit

- The distinct-pole argument uses three points with pairwise distinct
  `phi`, exactly the triples counted by the upstream router.
- It is applied on the projective normalization of each irreducible common
  component; no smoothness or algebraic closure assumption is hidden.
- A nonconstant map from a projective curve to `P^1` is surjective, so each
  distinct pole has a place above it.
- Positive-dimensional common components are not declared empty.  They are
  charged one target each through the already-proved first-match same-ray
  strip.
- Reducible conics and identically zero determinants are counted separately;
  the maximum remains three.
- The old `I_deg` router remains true but is superseded for this incidence.
