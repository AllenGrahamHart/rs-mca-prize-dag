# Attack surface

1. Try to reuse one cross-petal coordinate pair on two distinct lines.
2. Search for a balanced partition with `Q_L>X_L`.
3. Put two globally heavy points on a line that was charged as clean.
4. Search for `A/2<s<A` violating inequality `(6)`.
5. Exhaust small affine planes with all rich lines retained, not only one
   line per direction.
6. Duplicate a line deliberately; this must be rejected by the contract,
   since duplicate records would invalidate both injective resources.
