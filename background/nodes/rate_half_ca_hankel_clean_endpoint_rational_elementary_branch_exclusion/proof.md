# Proof

The elementary-modification theorem proves that `(REB1)` gives

```text
h^0(C,O_C(P_*))=2.
```

Its degree-one pencil is basepoint-free and defines a degree-one map from the
integral curve `C` to `P^1`. The same theorem proves that this makes `C`
isomorphic to `P^1`. In particular `C` is smooth and has genus zero.

On the other hand a smooth divisor of bidegree `(rho,m)` on
`P^1 x P^1` has adjunction genus

```text
g=(rho-1)(m-1)=(4m-2)(m-1).                         (1)
```

For `m>1`, equation `(1)` is strictly positive. This contradicts
`C isomorphic to P^1`, so `(REB1)` is impossible. The elementary-
modification dichotomy leaves only `(REB2)`, whose section count is one.
QED.
