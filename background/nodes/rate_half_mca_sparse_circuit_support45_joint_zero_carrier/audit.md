# Audit

1. The source completion counts are exact terminal-branch counts.
2. The source carriers include the deletion points as well as completions.
3. The first common-root bound is used only after the intersection is known
   to have positive dimension.
4. The contradiction at intersection dimension three uses an actual point
   in `U_4 intersect U_5` and the equality `H_4+H_5=V`.
5. `B` is the complete zero closure, so its vanishing space has common-zero
   set exactly `B` inside the evaluation domain.
6. `H_B subset H_5` gives the upper bound `t<=6`.
7. The label-space dimension in `E_B` is computed as `|B|-(10-t)`.
8. The final outside bound is uniform over every independent three-set, not
   only the source support-four deletion.
