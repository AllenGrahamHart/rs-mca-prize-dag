# Proof

Write

```text
q = k 2^128 + 1,
k = 340282366920938463463374607431768211201.
```

The integer `k` is odd and `k<2^128`, while

```text
3^((q-1)/2) = -1 (mod q).
```

Proth's theorem therefore proves that `q` is prime.  Also `2^41 | q-1`
and `q<2^256`, so `F_q` contains an element `zeta` of order `n=2^41`.
Taking `k_RS=2^40=n/2` makes this an admissible rate-half row.

Partition the exponents modulo `n` by their residues modulo `128`.  For
`I subset Z/128Z`, put

```text
B_I = {zeta^(a+128j) : a in I, 0 <= j < 2^34}.
```

For `1<=r<=t=2^33` and each residue `a`,

```text
sum_(j=0)^(2^34-1) zeta^(r(a+128j))
 = zeta^(ra) sum_(j=0)^(2^34-1) (zeta^(128r))^j
 = 0,
```

because `zeta^128` has order `2^34` and `2^34` does not divide `r`.
Thus every `B_I` is `t`-null.  If `1<=|I|<=64`, then

```text
t+16 < 2^34 |I| <= n/2,
```

so these sets lie in the central half-band.  Their number is

```text
C = sum_(m=1)^64 binom(128,m)
  = 182116756481433273164755097604074381602
  > 2^127.
```

Let `d=2^256-q`.  Exact arithmetic gives `t d<2^255`.  Bernoulli's
inequality now yields

```text
q^t / 2^n = (1-d/2^256)^t
          >= 1 - t d/2^256
          > 1/2.
```

Consequently the normalized unreduced central count satisfies

```text
X_unred >= C q^t / 2^n > 2^126 > 2^121.
```

Finally, every `B_I` is invariant under multiplication by the order-`2^34`
subgroup generated by `zeta^128`.  These are precisely quotient-periodic,
nonprimitive supports.  The exact-list split already assigns them to its
structured quotient column; they cannot also be charged to the primitive
DLI residue.  Hence the counterexample kills only the unreduced interface
and forces the printed primitive reduction.
