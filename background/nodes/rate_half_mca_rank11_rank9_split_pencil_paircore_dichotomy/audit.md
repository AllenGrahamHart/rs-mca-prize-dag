# Audit

1. The theorem is applied after lifting, so every record support has the
   original size `m` and the universal intersection floor is exactly
   `2m-n=134944`.
2. Two distinct slopes owned by one pair recover both received columns on
   their support intersection; this is why the intersection lies in the
   pair core rather than only in a slope-agreement set.
3. The lifted common core includes the residual ten-coordinate cell, so
   `j>=10` even when the deleted line-global core is empty.
4. Petals remain disjoint after lifting because deleted coordinates enter
   the common core of every owner.
5. The fixed-owner inequality is rewritten as
   `(t_p-1)(m-c_p)<=n-m`, avoiding a false independent multiplicity charge.
6. The key ordered-pair inequality uses only nonnegative integer factors:
   `D+1-x-y=(D-yx)+(y-1)(x-1)`.
7. The final quadratic endpoint is checked on both adjacent integers.
8. No count of affine owner planes or shared-core chronology is inferred.

No Modal computation is used.
