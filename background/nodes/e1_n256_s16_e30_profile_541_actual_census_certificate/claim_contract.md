# Claim contract

## Input

The exact 321-mask exceptional set from
`e1_n256_s16_e30_profile_541_relaxation_certificate`.

## Output

The complete actual-vector exceptional ledger: 440 vectors above the cubic
cutoff, exactly 86 with conductor one.

## Falsifier

An omitted normalized vector, a production/audit row mismatch, a failed
direct witness replay, or a different conductor count.

This node does not exclude the 354 proper-conductor or 86 primitive vectors.
