# Audit

1. Cancellation in `(PPQ3)` is by the monic polynomial `z-varphi`, not by
   a possibly nonunit element of the split residue algebra.
2. `S_n^perp=S_d` uses `d=R-n-2` and the nondegenerate residue pairing; it
   is an equality by dimensions, not only the usual low-degree vanishing.
3. Multiplication by `J` is invertible only in `A`; no polynomial-degree
   bound is assigned to `JQ_i` before reduction modulo `L_U0`.
4. `xi` is a right-radical excess. It is not a new conjectural defect and
   neither sign-free case closes Shape A.
5. The route ruling corrects the earlier suggestion that ambient
   common-kernel dimension could itself improve the separation-rank floor.
