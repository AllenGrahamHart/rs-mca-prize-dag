# Audit

1. The projective dimension is conditional only on atom nonemptiness; an
   empty atom is already paid.
2. The embedding counts split locators on all of `H`, a superset of locators
   split on `C`.
3. The common-gcd proof uses an actual core-split member and the mu-basis
   determinant; dimension arithmetic alone would not prove primitivity.
4. Sub-balance is an average-scale statement and does not imply maximum
   flatness.
5. Odd `a` removes pure multiplicative pullbacks only, not reciprocal or
   dihedral strata.
6. No existing Conjecture-F edge is activated without a proved FPC5 owner
   transport.
