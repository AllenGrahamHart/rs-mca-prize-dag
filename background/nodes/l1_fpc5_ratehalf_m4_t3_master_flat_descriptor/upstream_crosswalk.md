# Upstream crosswalk

This descriptor is a concrete LIST-side instance of upstream
`prob:capfr1-master-flatness` and the BC class of the shared census kernel:

```text
full smooth root domain, no punctures;
degree j=2ell-a;
projective dimension r=ell-2a+1<j/2;
codimension ell+a-1;
flat-wide gcd one;
generated-field normalized mean <2^(-3ell-4).
```

It is stronger than a generic proper-flat pose in three ways: the dimension
ratio is below one half, the mean is far below one, and the tangent/common-
divisor branch is absent. For odd defects the pure multiplicative pullback
branch is absent as well.

The remaining primitive assertion is exactly maximum-versus-average
split-flatness. For even defects, quotient recursion and for all defects any
dihedral classification must also preserve the FPC5 first-owner ledger.
Until that transport is proved, this node is evidence for the shared kernel,
not a new strict consumer of the current `conj_f` assembly.
