# Rate-half FPC5 `M=4,t=3` master-flat descriptor

- **status:** PROVED
- **consumer:** `l1_fpc5_ratehalf_m4_t3_split_slice_payment`
- **upstream interface:** split-locator master flatness / BC class

Fix one official rate-half guarded LS6 atom in the Johnson-nonpositive tail.
Write

```text
n=8ell+2b-2,       j=2ell-a,       1<=a<=floor((b-3)/4),
P=P(W_(lambda,a)^<=j).
```

If the atom is nonempty, then `P` is an unpunctured full-domain projective
split-flat descriptor with

```text
root domain:             H, |H|=n;
locator degree:          j=2ell-a;
projective dimension:    r=ell-2a+1;
projective codimension:  j-r=ell+a-1;
root threshold:          j;
common locator gcd:      1.                              (MF1)
```

Every LS6 divisor maps injectively to a point of

```text
P intersect D_j(H),                                      (MF2)
```

where `D_j(H)` is the set of degree-`j` locators split completely on the
full smooth domain. Passing from the source core `C` to `H` and deleting the
LS6 exactness guard only enlarge the set.

The descriptor is quantitatively proper:

```text
j-2r=3a-2>=1.                                           (MF3)
```

It is also strictly sub-balance at every official row. Let `B_0` be the field
generated by `H` and the flat coefficients, and put `Q=|B_0|`. Then

```text
binom(n,j)/Q^(j-r)
 <=2^n/Q^(ell+a-1)
 <=2^(-3ell-4)<1.                                      (MF4)
```

Finally, a pure multiplicative `M`-pullback point can occur only for

```text
M|gcd(n,j).
```

Since `n` is dyadic, all nontrivial scales are dyadic; when `a` is odd,
`j` is odd and the pure multiplicative pullback stratum is empty.

## Scope

This is an exact consumer descriptor, not a max-to-mean theorem. It does not
bound the primitive points of `(MF2)`, pay even-`a` quotient strata, handle
dihedral pullbacks, or transport the current consumer-scoped Conjecture-F
owners into the FPC5 first-owner ledger.
