# Result

Structured evaluation domains defeat naive far-CA counting: on the
negation-closed domain the official row shape realises, an exact
parity-collapse mechanism mass-produces bad slopes at `rho = 2`
(`T = 95..98` against `r+1 = 9`, `750x` over the first moment, field-size
independent), so any argument treating the domain as a generic point set is
unsound at small rho.

The same mechanism is condition-killed at the razor: with `M = 2` the
carrier is over-determined by exactly `2^33 - 1` conditions — a
rho-threshold, `q`-free. The excess is therefore a small-rho pathology, not
a razor threat, and the razor cap must come from the pigeonhole in the
crossing-offset value ledger (the proved `<= r+1` bound stops at
`r <= R/2`, below the crossing offset). Deliverables of record: (NCE), the
corrected count (CNT), the H3 locator-vs-slope distinction, and the shape
scoping.
