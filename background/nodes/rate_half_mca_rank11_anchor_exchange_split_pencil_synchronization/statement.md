# Anchor-exchange synchronization of rational exception pencils

- **status:** PROVED
- **scope:** the dense anchor in the triple-owner heavy-ruling packet
- **dependencies:** the pole-simple packet router and exception split-pencil
  normal form

Fix once and for all:

1. the dense anchor pair `p_0` and any fixed set of exactly `5524` of its
   owned slopes;
2. the `t` secondary pair types recovering the triple-owner core, where
   `1<=t<=4`;
3. three owned slopes from each secondary type; and
4. one core-saturated exact support for every record in the fixed anchor set
   and every fixed secondary record.

Put

```text
s=32-3t,       20<=s<=29.
```

Choose a base set `A_0` of `s` anchor slopes and one distinguished
`alpha in A_0`. For every anchor slope `eta notin A_0`, form the admissible
one-swap packet

```text
A_eta=(A_0\{alpha}) union {eta},
```

using the same fixed secondary records and supports.

Applying the existing exact trichotomy to the base packet and all one-swap
packets gives the following unconditional alternative:

1. at least one packet emits `chi>=2299571`; or
2. every packet is rational, and one fixed coprime polynomial pencil of
   degree `e in {1,...,11}` contains the exception locators of all `5524`
   fixed anchor records.

This is a packet-pencil synchronization theorem for the dense anchor. It
does not pay the high-complexity output or classify the synchronized pencil.

## Falsifier

An inadmissible one-swap packet, packet-dependent residual anchor core, fewer
than two common nonproportional locators between rational packets, or two
different two-dimensional polynomial subspaces containing the same two
linearly independent locators.
