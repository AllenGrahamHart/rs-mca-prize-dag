# Claim contract

This is a deterministic cross-support carrier theorem in the same
dimension-ten generalized-MDS circuit model as the completion ladder.

It compares abstract circuit-label representations only when their support
union has size at most `K`; hence Vandermonde independence makes the
comparison representation-safe.  It does not pair received values with an
abstract quotient label.

The node supplies no component payment, owner chronology, rank-eight
statement, active-v4 movement, or prize closure.
