# Frontier

Use the exact maps in the five fields `K[s]/(phi_j)`:

1. translate each already-defined source-square, nonzero, collision, and
   chart guard into `s`;
2. compute its resultant/norm against each `phi_j`;
3. separate identically zero residue components from finite exceptional
   `t` loci;
4. append the residual colored `BE` cubic and unsquared sum only on
   surviving components;
5. return a unit certificate or an exact surviving residue factor.

Do not recompute the pair quotient, stable basis, primitive polynomial,
factorization, or coordinate maps.
