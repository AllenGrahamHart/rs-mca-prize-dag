# Audit

The proof uses the imported affine-span compiler only at direction dimension
one. The rank-two conclusion is then derived by exact incidence counting.

The strict endpoint matters. At `3d-1`, `(3)` forces equality throughout.
Moving the agreement threshold down by one no longer forces `z=2d-2`, so
the proof is not silently widened. The final six-pair count uses distinct
affine-linear quotients and the fact that `Q(x)!=0` outside `G`.

The official rows have `d` far above three. The theorem is stated for the
minimal range actually proved.
