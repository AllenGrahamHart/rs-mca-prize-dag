# Frontier

Use the full divided scalar-locator identity, not only the support sets. The
next useful invariant should couple

```text
Q'(p0_i+gamma_i p1_i)
  +(c0+c1 gamma_i)Lambda_i'
  = A'+gamma_i B'
```

across indices. A successful route must force a common owner/correction
space or a row-sharp image bound; another pure constant-weight packing bound
is unlikely to close the million-bit gap.
