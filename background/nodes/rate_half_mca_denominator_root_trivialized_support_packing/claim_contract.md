# Claim contract

## Proved

- uniqueness of the punctured explaining pair for each trivialized support;
- pairwise reduced-support intersection at most `k-1`;
- disjoint `k`-shadows and the exact binomial packing bound;
- a uniform exact fence showing that this bound exceeds both row budgets.

## Not proved

- that the actual number of trivialized slopes exceeds either budget;
- optimality of the shadow bound among all possible arguments;
- any count using the scalar-locator identity beyond support interpolation;
- denominator-root or complete exception payment.
