# Result

The old bivariate matrix enforced that `L_x(Y)Q_Y(x)` is a shortened
apolarity-code word. It did not separately enforce that the locator values
`Q_Y(x)` come from `X`-degree-`rho` polynomials.

The missing condition is another explicit linear block, `E_W`. The live
rank target is now the combined matrix `C_W=[M_W;E_W]`. This strengthening is
chronology-valid and preserves the proved `m=1` counterexample, so it does
not manufacture rank by discarding a genuine failure.
