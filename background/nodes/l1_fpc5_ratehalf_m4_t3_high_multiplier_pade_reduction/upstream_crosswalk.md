# Upstream crosswalk

The high-multiplier branch is not an arbitrary split flat. It is the image
of the affine rational-approximation condition

```text
deg rem_E(MQ)<=ell-a
```

under `Q -> quo_E(MQ)`, with the exact primitive guard
`gcd(Q,quo_E(MQ))=1`. The inverse multiplier must simultaneously lie in the
top-degree band `deg(E^(-1) mod M)>=ell+a`.

This is a source-side instance for upstream split-pencil, SPI, and primitive
quotient-fiber control. Any census may work in the smaller `Q` coordinates,
but still must prove splitness/maximum control and preserve the FPC5 owner.
