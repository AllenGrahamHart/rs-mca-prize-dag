# Claim contract

This theorem assumes a ten-dimensional subspace of `F[X]_<13`, distinct
evaluation coordinates, and an empty global common zero set on the selected
record support.  It counts only eleven-sets on which evaluation has rank ten.

The structured branch is triggered by three **circuit** completions of one
independent set, not merely by three arbitrary common zeros.  The
unstructured count uses the fact that a full-rank eleven-set cannot contain
two distinct quotient labels.

No classification of planes in secant varieties, component-incidence
density, kernel capacity, rank-nine chart bound, chronology rule, or prize
row closure is part of this theorem.
