# Result

The zero-exception random `m=2` profile did not establish an incidence-level
theorem. A deliberately structured inverse-pair construction produces an
exact rational trace and an all-nonzero kernel for the complete old matrix.

The failure is diagnosed, not merely exhibited: it is removed by the new
locator-extension rows. This redirects the live route from full rank of
`M_W` to full rank of `C_W=[M_W;E_W]` and prevents the bounded random profile
from being promoted beyond its actual scope.
