# Audit

1. The model is geometric and explicitly does not instantiate the fixed
   KoalaBear endpoint record.
2. The parameter `b=-1` is allowed and is the rational-source specialization
   `b^2=a+2` for `a=-1`.
3. The two factors in `(KBM3G-2)` are distinct source-deck conjugates; the
   diagonal cubic factor is not confused with the residual component.
4. Pole values avoid `+/-2`, the complete branch-value set of the composed
   source maps, so all six poles, twelve labels, and 24 locator roots are
   distinct.
5. Divisibility follows from the common `D_3` value; saturation then uses
   the local degree-two bound and equality of total degrees.
6. The result forbids only a geometry-only deletion strategy. It neither
   proves nor refutes compatibility with the fixed active pencil.
