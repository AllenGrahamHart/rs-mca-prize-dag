# Audit

- Exact deficit `e` gives exactly `m-e` outside agreements, so ownership
  forces agreement on all `e` exceptional coordinates.
- Evaluation on `E` is invoked only under the explicit condition `e>=K`.
- Different terminal slopes give different explanations because `q` is
  nonzero on its support.
- The affine-line direction is a nonzero degree-`<K` codeword, so its
  outside zero core has size at most `K-1`.
- Outside the common core, each coordinate can serve at most one line
  parameter.  This is a packing statement, not a second-moment estimate.
- Prefix suffix minima stop at `e-1`; no unavailable terminal cumulative cap
  is silently imported.
- KoalaBear stops because the next `h=e-1` cap is unavailable.  Mersenne
  stops on a valid but over-budget profile.  Neither is an unsafe
  certificate.
- All scans use exact integers and negligible memory.
