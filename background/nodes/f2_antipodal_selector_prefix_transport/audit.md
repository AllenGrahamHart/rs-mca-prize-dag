# Audit

1. The selector has size `m` for every binary Hamming weight; it is not the
   original fixed-weight decomposition.
2. Even power sums are fixed because every antipodal pair contributes the
   same even power. Odd power sums carry the syndrome by an affine map with
   invertible factor `2`.
3. The target ambient fiber fixes all first `2R` moments, not only the odd
   moments.
4. Newton requires `2R<p`; this holds on the official F2 rows but remains a
   stated hypothesis of the generic theorem.
5. Forgetting the transversal condition is an upper-bound injection. It is
   not equality with the full split-locator fiber.
6. Upstream master flatness removes structured components before asserting
   its bound. Quotient-periodic supports are absent on the selector image,
   but common-divisor subfamilies and their ownership remain to be handled.
