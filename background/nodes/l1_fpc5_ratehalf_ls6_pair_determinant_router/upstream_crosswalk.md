# Upstream crosswalk

The pair determinant

```text
H_12=D_1Q_2-D_2Q_1
```

is the primitive shift-pair invariant of one LS6 Pade cell. It has degree at
most `ell-2a`, contains the common split-locator factor, and separates every
candidate relative to a fixed base. The live tail is exactly where its
pairwise Johnson denominator is nonpositive.

This is a direct source for upstream SPI/split-pencil control: any successful
census must use compatibility among several low-degree determinants or their
split factors, rather than only the induced pairwise support distance.
