# Claim contract

- **Claim:** for every `q in {0,...,n}`, one all-nonzero static source
  has exact middle-Hankel corank one and omitted-recurrence run length
  exactly `q`.
- **Currency:** Lagrange leading-coefficient extraction and the residue
  pairing on the squarefree roots of `Q`.
- **Characteristic:** unrestricted, subject only to enough distinct field
  elements for `U`, the roots of `Q`, and one root of `G`.
- **Dependency:** the Shape-A omitted-recurrence bordered-Hankel flag,
  solely to identify the route being fenced.
- **Nonclaim:** no global parameter pencil, source partition, split biform,
  scalar weld, or collision packet is constructed.
- **Falsifier:** a failed exact-corank assertion, a zero source weight, or
  any `q` for which `R_(d+1+q)` vanishes.
- **Next gate:** use coupling across parameter values; static source
  nonvanishing and bordered determinants cannot supply non-stagnation.
