# e1_official_prime_exception_control

- **status:** TARGET
- **closure:** open

## Statement

Uniformly for every row whose adjacent-unsafe certificate invokes the direct
E1 quotient-value route, with its generated field and cyclotomic reduction
prime/ideal pinned, incidence in the open cells `N' in {128, 256}` with the
explicit non-quotient `e_1` exceptional norm-divisor set is negligible
relative to the signed-core quotient count at the scope required by
`e1_fullness`.

An alternative based on direct folded lattice/kernel certificates must cover
every row assigned to that route. Certificates for finitely many named exhibit
fields establish only those exhibits; without a route-uniform transport theorem
they do not discharge this node. The separate target
`unsafe_crossing_family_instantiation` owns the proof that every admissible row
has some valid unsafe-side payload.

## Falsifier

A row assigned to direct E1 with enough non-quotient folded sparse kernel
vectors to make `e_1` collisions exceed the allowed budget. A purported
certificate route is also defeated if it leaves any assigned row
uncovered.
