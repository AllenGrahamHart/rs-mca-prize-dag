# Result

The proposed bare Layer-A rank theorem is false. At its first positive-count
case `m=2`, a saturated `26 x 24` system can have rank only 20.

The useful replacement target is narrower: prove full rank only after adding
the canonical pair-union support, complete block, intersection, split-biform,
and Hankel/source hypotheses. The canonical `m=2,3` measurements remain
evidence for that stronger statement, but the polynomial count cannot prove
it by itself.
