# KoalaBear m2 r4 order-two orientation trichotomy

- **status:** PROVED
- **scope:** actual residual components of type
  `(m,r,delta)=(2,4,2)`

Let `tau` be the deck involution of the terminal quadratic endpoint map and
put

```text
V4=<tau x 1, 1 x tau>.
```

Every actual component in this type has one of exactly three order-two
stabilizers. The two coordinate stabilizers

```text
<tau x 1>, <1 x tau>
```

are one existence/deletion route under endpoint transposition, provided the
source record is reconstructed after transposition. The diagonal stabilizer

```text
<tau x tau>
```

has exactly two source-field branches:

1. a reciprocal source-line lift when the diagonal action preserves the
   quadratic source intermediate field;
2. a biquadratic source cover when it does not, with source genus zero or
   one and the exact proved `V4` branch passports.

This theorem classifies actual components. It does not identify active
first-match bad slopes with components, does not cover the separate
trivial-stabilizer `(m,r,delta)=(2,8,1)` type, and does not delete or pay any
branch.

## Falsifier

An actual `(2,4,2)` component with a stabilizer outside the three displayed
subgroups, failure of coordinate transposition, or a diagonal component
outside the source-line/source-cover dichotomy.
