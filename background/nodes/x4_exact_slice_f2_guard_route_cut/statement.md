# Official exact-slice F2 guard route cut

- **status:** PROVED
- **closure:** proof

Put `N=2^41`, let `rho` be one of `1/2, 1/4, 1/8, 1/16`, and put
`K=rho N`. For an official field write `L=log2(q)`, with
`128<=L<256`. Define the exact-list corridor depth by

```text
t_XR=min{t>=0 : tL >= log2 binom(N,N-K-t)+128}.        (XR)
```

Then

```text
t_XR L <= N-129.                                       (CUT-1)
```

If `B0=F_p(mu_N)` is the field generated by the smooth domain, then
`B0` is a subfield of `F_q`, so

```text
t_XR log2|B0| <= t_XR L <= N-129.                      (CUT-2)
```

Hence every official exact-slice corridor depth fails the F2 consumer guard
`|B0|^t>=2^N` by at least `129` bits. This includes rows with `B0=F_q`. The
guarded full-subset F2 terminal therefore cannot by itself discharge the
exact-slice `u2c/x4` consumer.
